# 모바일 게임 UI 이미지 가이드

현재 이미지 시안은 **rev3 기본 8장과 추가 21장, 총 29장**입니다. 사용자가 선호한 rev3의 구도·버튼 배치·차분한 데님 블루·코럴·골드와 조금 더 사실적인 재질 방향을 추가 화면에 적용했습니다. 밝고 경쾌한 아케이드 레이싱 분위기와 단순한 UI는 유지합니다. 흰 아이콘과 선택 표시는 배경에서 구분되도록 남깁니다.

실사감은 차량 도장의 반사·유리의 깊이·타이어와 금속의 재질, 접지 그림자, 아스팔트·물·바위·식생의 질감과 자연광으로 보강합니다. 버튼과 패널은 같은 평면 스타일을 유지하며, 광택·입체 테두리·네온 장식을 더하지 않습니다. 어두운 영화식 색보정이나 과한 반사·흐림으로 바꾸지 않습니다.

기본 구도 8장은 그대로 보존합니다. 시작 화면을 실제로 반영할 때는 패스포트 진입이 추가된 [start_passport.png](reference/rev3/start_passport.png)를 우선 사용합니다. 아래 추가 상태는 같은 rev3의 확장이며 별도 리비전이 아닙니다.

제목·차명·코스명·버튼 문구는 번역 가능한 실제 텍스트를 얹도록 비워 두었습니다. 이미지 속 차량·코스 그림·성능 막대는 시안용이며 실제 모델·수치·트랙 중심선을 대체하지 않습니다. 구현 단계에서는 휴대폰·폴드의 안전 영역, 긴 번역, 44px 이상의 터치 영역을 별도로 확인합니다.

이미지는 생성 도구의 원래 바이트와 크기로 보관합니다. 좌표를 옮길 때는 `source.json`의 실제 이미지 크기를 기준으로 배율·원점을 공통 적용하며 그림에 그린 버튼의 픽셀 좌표를 다른 크기 화면에 그대로 사용하지 않습니다. 정적 장식과 동적 컨트롤을 분리한 뒤 같은 변환으로 그림·문자·터치를 맞춥니다.

시작의 두 큰 버튼은 투어·트랙 진입에 연결합니다. 패스포트와 설정은 우측 상단의 별도 버튼입니다. 이 진입 방식으로 모드 선택을 함께 처리하며 불필요한 중간 선택 화면을 추가하지 않습니다. 작은 상단 버튼도 안전 영역 안에 두고 실제 터치 영역과 버튼 사이 간격을 확보합니다.

로딩의 진행률·회전 표시·버전·단계·팁은 실제 값으로 그립니다. 긴 로딩은 전용 원화를 사용하고 짧은 전환은 같은 환경판 위 간단한 표시로 처리합니다. 두 상태를 중복 팝업으로 겹쳐 띄우지 않습니다. 날씨·시간은 트랙 선택의 실제 저장값과 연결하며 설정 화면에 다시 추가하지 않습니다. 선택 카드의 풍경은 코스 소개용이며 비·야간 선택만으로 카드 전체를 어둡게 만들 필요는 없습니다.

패스포트의 도착지 순서는 [route_library.gd](../../scripts/track/route_library.gd)의 최종 행과 같은 협곡·항만·대나무길·설산·화산해안입니다. 경로 16개와 메달·해금은 [tour_passport.gd](../../scripts/race/tour_passport.gd)의 실제 상태를 표시합니다. 그림의 완료·미방문·잠금 조합과 도장 색은 예시이며 새 보상이나 해금 조건을 추가한 것이 아닙니다. 조작 설정은 현재 좌우 배치·크기·초기화 기능에 연결하고 표시된 선택값을 고정하지 않습니다.

HUD의 빈 정보 영역에는 코스명·순위/스테이지·랩/남은 시간·경과 시간·속도·기어를 실제 텍스트로 표시합니다. 투어와 트랙은 같은 상단 배치와 지도 영역을 공유하며, 지도 내용만 실제 경로·노드로 교체합니다. 조이스틱과 브레이크 중심 높이를 맞추고, 미니맵은 보이지 않는 프레임이 아니라 실제 지도선의 윗부분을 상단 기준에 맞춥니다.

투어 지도는 아래 출발점 하나부터 위 도착지 다섯 곳까지 총 15개 노드를 연결합니다. 지역 선택의 두 칩은 실제 다음 지역명·특징·선택 상태를 표시합니다. 트랙 지도와 카드의 흰 코스 선은 실제 중심선으로 교체합니다. 원화의 도로 분기·차량 수·마커 수·코스 선을 게임 데이터로 사용하지 않습니다.

일반 출발과 롤링 스타트는 같은 출발 신호 부품을 공유하고 실제 카운트·출발 상태에 맞춰 점등합니다. 트랙2의 5초·16대·플레이어 약 10위 출발은 현재 경기 로직을 따르며 그림에 보이는 차와 점의 개수로 정하지 않습니다. 신호 테두리와 동적 글자는 야간에도 읽히도록 밝게 유지합니다. 주행 상태 비교표는 서로 다른 네 순간을 한 장에 놓은 자료이며 게임 화면 전체에 동시에 올리는 레이아웃이 아닙니다. 알림은 해당 이벤트 동안만 표시하고 차·도로·조작을 가리지 않습니다.

설정의 슬라이더·토글, HUD의 게이지·지도·마커·조이스틱은 이미지에 그린 예시 상태입니다. 게임 반영 시 정적 장식과 동적 컨트롤을 분리하고 실제 저장값·주행 상태를 연결합니다. 일시정지 창을 열면 배경 주행 조작의 입력을 막고, 복귀 동작은 현재 모드의 선택 화면에 연결합니다. 이 시안 제작으로 실제 옵션·주행·저장 로직을 변경하지 않습니다.

튜닝샵은 도장·리버리·휠·리어윙·셰이딩·이펙트의 여섯 분류를 표현합니다. 그림의 도장·마감 선택은 예시이며 실제 카탈로그·장착 가능 여부·저장값에 연결해야 합니다. 차량 옆 화살표는 미리보기 시점 조작용이며 차량 선택을 바꾸지 않습니다. 비교·초기화·취소·적용은 기존 초안과 저장 경계를 유지합니다.

이펙트 슬롯은 차량 정의에 따라 1~3개를 표시하며 그림의 한 슬롯을 모든 차의 고정 규격으로 사용하지 않습니다. 오픈카 지원 여부와 셰이딩 강도도 차량별 실제 선택을 따릅니다. 색상 확인은 편집 중 초안만 변경하고 최종 적용이 저장을 확정합니다. 변경 폐기 확인과 색상 창이 열려 있을 때는 배경 입력을 막고 뒤로가기는 최상위 창부터 닫습니다. 탭은 아이콘의 화면상 위치가 아닌 기능 식별자에 연결하여 셰이딩·이펙트가 뒤바뀌지 않게 합니다.

결과 화면은 중계 카메라와 차량·코스를 넓게 보여 주고 우측 패널에 실제 확정 기록을 얹는 구성입니다. 화면 전체를 불투명하게 덮거나 배경을 흐리게 만들지 않습니다. 순위·시간·베스트 랩·점수와 최고 기록 표시는 실제 결과에 따라 표시하고, 완주·실패 문구와 아이콘도 상태에 맞게 구분합니다. 기록 확정과 이후 차량 연출을 분리하며 선택 화면 복귀는 현재 모드의 기존 경로를 따릅니다.

결과 상태별 기록의 의미는 라벨과 실제 값으로 구분합니다. 실패에는 완주 메달·신기록 축하를 표시하지 않으며, 신기록과 보상 띠는 실제 확정 상태가 있을 때만 표시합니다. 재시도는 현재 모드·차량·코스 설정을 유지합니다. 선택 화면 복귀는 트랙 경기에서 트랙 선택, 투어 경기에서 투어·트랙 모드 선택으로 연결하며 투어 결과의 화살표를 다음 스테이지 진행으로 해석하지 않습니다. 도장 해금 띠는 신규 구매·경제 시스템을 뜻하지 않습니다.

생성 파일·크기·해시·화면 간 참조 관계와 화면별 연결 목록은 [rev3/source.json](reference/rev3/source.json)에 기록합니다. 차량 선택 화면의 재질과 빛을 먼저 정하고 나머지 화면에 같은 방향을 적용했습니다. 추가 화면은 해당 기본 rev3 화면을 참조하며, 패스포트·투어 HUD의 중간 수정 입력도 출처에 기록합니다.

[rev2](reference/rev2/source.json)는 구도·색상·재질 비교용, rev1은 색상 비교용으로만 보존합니다: [시작](reference/rev1/start.png)·[트랙 선택](reference/rev1/track_select.png)·[차량 선택](reference/rev1/car_select.png). 현재 기준은 rev3이며 서로 다른 리비전의 부품을 섞지 않습니다.

이 폴더의 시안은 Godot 임포트와 제품 내보내기에서 제외합니다. 현재 게임 아트의 재생성 원본은 [runtime_sources](runtime_sources/README.md)에 분리하며 새 디자인 참고로 사용하지 않습니다.
