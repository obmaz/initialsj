# 시작 전 화면 이미지 가이드

현재 디자인 후보는 아래 세 장입니다. Horizon Chase Turbo의 경쾌한 아케이드 레이싱 분위기를 참고해 새로 제작했으며, 기존 게임 화면을 입력 이미지로 사용하지 않았습니다. 세 화면은 코발트 블루의 단순한 면, 코럴 실행 버튼, 노란 선택 표시와 밝은 풍경을 공유합니다.

| 화면 | 이미지 | 구성 |
| --- | --- | --- |
| 시작 | [start.png](reference/start.png) | 주인공 차량, 제목 자리, 큰 진입 버튼 두 개 |
| 트랙 선택 | [track_select.png](reference/track_select.png) | 큰 코스 카드 세 장을 넘기는 구성, 날씨·시간, 진행 버튼 |
| 차량 선택 | [car_select.png](reference/car_select.png) | 차량 미리보기, 성능, 차량 카드, 튜닝·출발 버튼 |

가로형 모바일 화면을 위한 **시안**이며 게임에는 아직 적용하지 않았습니다. 새 디자인을 검토할 때는 이 세 장을 함께 사용합니다. HUD·설정·튜닝샵의 새 디자인까지 정의한 자료는 아닙니다.

제목·차명·코스명·버튼 문구는 번역 가능한 실제 텍스트를 얹도록 비워 두었습니다. 이미지 속 차량·코스 그림·성능 막대는 시안용이며 실제 모델·수치·트랙 중심선을 대체하지 않습니다. 구현 단계에서는 휴대폰·폴드의 안전 영역, 긴 번역, 44px 이상의 터치 영역을 별도로 확인합니다.

생성 파일·크기·해시·화면 간 참조 관계는 [source.json](reference/source.json)에 기록합니다. 이 폴더의 시안은 Godot 임포트와 제품 내보내기에서 제외합니다. 현재 게임 아트의 재생성 원본은 [runtime_sources](runtime_sources/README.md)에 분리하며 새 디자인 참고로 사용하지 않습니다.
