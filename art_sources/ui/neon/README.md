# 네온 UI 레퍼런스

[reference_board.png](reference_board.png)는 현재 게임 캡처를 바탕으로 OpenAI 이미지 생성 도구로 새로 제작한 4종 UI 기준입니다. 상단 왼쪽은 HUD, 오른쪽은 카운트다운, 하단 왼쪽은 설정, 오른쪽은 결과입니다. 인수인계에서 이름만 남아 있던 과거 원화를 복구한 파일이 아닙니다.

이 원본은 향후 작업에서도 같은 기준을 찾을 수 있도록 Git에 보존합니다. 픽셀 좌표·해시·제작 기준은 [reference.json](reference.json)에 기록합니다. 이 폴더는 `.gdignore`와 내보내기 제외 규칙을 적용한 디자인 원본이며 APK/Web 런타임에 포함하지 않습니다. 생성 원본은 로컬 `generated_images/exec-2b9dc209-0611-4205-a88f-8134b3f9647b.png`에도 남겨 둡니다.

원화에는 글자를 넣지 않았습니다. 게임의 제목·통계·안내·버튼 문구는 번역 가능한 실제 텍스트로 구현합니다. 검증 시 움직이는 3D 배경·차량이나 수치 자체가 아니라 UI 위치·면적·색·도형·장식·가독성을 비교합니다. 이 작업은 차량·오브젝트·공간 셰이더·주행·광원을 변경하지 않습니다.
