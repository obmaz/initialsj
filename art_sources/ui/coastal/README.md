# 시작 전 해안 UI 원화

[master.png](master.png)는 OpenAI 이미지 생성 도구로 만든 글자·차량 없는 공통 원화입니다.
원본은 `/workspace/generated_images/exec-336625bf-e3bb-4146-8d9c-f736d7b390bd.png`에 보존합니다.
[backdrop.png](backdrop.png)는 같은 원화를 참조해 UI를 제거한 환경판이며 생성 원본은
`exec-3febe3e1-c23c-42a2-a9bc-aecf18d875b4.png`입니다.

[재단·배치·해시 정본](layout.json)은 [베이크 도구](../../../tools/bake_pre_race_art.py)가 관리합니다.
실행 전 Pillow를 설치하고 `python3 tools/bake_pre_race_art.py`로 재생성합니다.
도구는 원본을 보존하고 원화의 실제 프레임 픽셀을 잘라 모서리 밖만 알파로 제거합니다.
프레임의 모서리·금속·반사·질감을 다시 그리지 않습니다. 배포 폴더는
[assets/ui/pre_race/](../../../assets/ui/pre_race/)입니다.

시작·홈(모드 선택)·코스·차량·설정의1280×720 통이미지는 환경을 포함하지 않는 투명 RGBA 프레임 이미지이며, 중앙 UI 배치의 정본입니다.
공유 환경판 한 장을 기기 전체에 cover로 그린 뒤 현재 프레임 통이미지·실제 글자·차량·성능·선택·설정 값을 중앙 안전 영역에 합성합니다.
환경을 중앙 이미지에도 굽지 않아 중앙·바깥 사이에 서로 다른 배경 배율의 경계가 생기지 않게 합니다. 원화 프레임의 현재 입력 Rect는 유지합니다.
차량 선택에서만 환경판을 그리는 동안 수평 반전 변환을 적용합니다. 전시대를 실제 차량 쪽에 가깝게 두는 런타임 처리이며,
원본이나 별도 반전 텍스처·프레임 좌표·실제 차량 카메라는 바꾸지 않습니다.
엔진 최초 스플래시는 `backdrop.png` 환경판만 사용합니다. 실제 부트·긴 로딩의 LoadingOverlay는 환경판·`start.png` 투명 프레임·실제 제품명·진행 상태를 합성합니다.
Android와 Web의 설정 푸터 수가 달라 해당 버튼은 같은 재단 이미지로 실행 시 그립니다.
공통 버튼·헤더·패널과 조작 설정도 같은 조각으로 기존 기능을 보존하며 밝은 계열을 사용합니다. 런타임9분할은 원본의20px 재단 여백을 고정하고 목적지 여백만 `min(20, 너비/3, 높이/3)`으로 제한합니다.

[배포 환경판](../../../assets/ui/pre_race/backdrop.png)은 기기 전체를 종횡비 보존 cover로 채우는 공용 아트입니다. 부팅·시작 전 메뉴의 Window 콘텐츠 정책은 `EXPAND`를 사용하며, 중앙 통이미지·텍스트·입력은 같은1280×720 안전 영역 변환을 사용합니다. 주행 진입 때 기존 `KEEP` 정책을 복원합니다. 대형 메뉴 아트는 현재 투명 프레임 통이미지 한 장과 공용 환경판 한 장을 보유하고, 주행 진입 때 두 이미지의 참조와 미리 읽기를 모두 해제합니다.

원본 폴더는 Godot 임포트·배포에서 제외합니다. 실제 화면 캡처·역할별 작업 기록·최대5회 검증 기록은
`build/reports/pre-race-art/`에 둡니다. 계획은 [개발 계획](../../../docs/PRE_RACE_ART_PLAN.md)을 따릅니다.
