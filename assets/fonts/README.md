# HUD fonts

- `Roboto-BoldItalic.ttf`, `Roboto-BlackItalic.ttf`: unmodified Roboto font binaries, copyright Google Inc. [Source](https://github.com/googlefonts/roboto-2/tree/main/src/hinted), [Apache License 2.0](Roboto-LICENSE.txt).
- `PositionNumeral.tres`: FontVariation of Roboto Black Italic with extra weight for race positions.
- `LiberationSans-BoldItalic.ttf`: unmodified Liberation Fonts. [SIL Open Font License and attribution](LICENSE.txt).

The font license texts are included in the Web export.
