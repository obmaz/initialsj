# rev3 UI 출처

디자인·분리 원본은 [UI 이미지 가이드](../../../art_sources/ui/README.md), [에셋 제작 계약](../../../art_sources/ui/kit/rev3/README.md)을 따릅니다.

OpenAI image_gen으로 제작한 원화에서 UI 부품을 분리했습니다. 주행·결과의 월드 스냅샷과 원화 비교용 배경은 설치하지 않습니다. 좌표·아틀라스·PNG는 tools/install_rev3_ui.py로 생성합니다.

Noto Sans KR는 Google Fonts 배포본이며 [OFL 라이선스](fonts/OFL.txt)를 함께 제공합니다.
