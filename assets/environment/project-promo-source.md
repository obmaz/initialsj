# 프로젝트 홍보 광고

`project-promo-ads.png`는 이미지 생성 도구의 원본 `exec-4241ef5d-530b-4d69-8d37-4b12ae8d9aa1.png`를 그대로 복사한3열×2행 광고 아틀라스이다. 위 행은 SJRPG3종이며 모두 개발 중임을 표시한다. 아래 행은 킹왕짱 RPG3종이며 영단어 학습·전투·장비 수집을 표현한다. 사용자가 소유한 프로젝트의 홍보 요청으로 제작했다.

실제로 첨부한 참조는 SJRPG의 `assets/source/style/approved-game-reference.jpg`와 `obmaz/fantasyword`의 `docs/design/approved-lobby.webp`이다. 킹왕짱의 내용·주소·시각 방향은 해당 저장소 README와 `docs/design-assets.md`를 확인했다. UI 자체를 광고로 복사하지 않고 새 홍보 구도를 생성했다. 원본 이미지를 리사이즈하거나 분할 저장하지 않고 셰이더가 각 칸을 선택한다.
