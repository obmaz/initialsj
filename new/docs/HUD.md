# 레퍼런스 기반 레이싱 HUD

`hud-comparison.html`에서 첨부 이미지와 실제 Godot 렌더링을 나란히 확인할 수 있습니다. `preview_hud.gd`가 설정하는 수치는 비교용이며, 실제 게임 데이터에 영향을 주지 않습니다.

1280×720을 기준으로 비율을 유지해 축소·확대하고 가운데에 배치합니다. 터치 좌표에도 같은 역변환을 적용합니다.

| 영역 | 배치 |
| --- | --- |
| POS / 순위 | 좌상단 (8, 14), 노란 순위, 흰 전체 인원 |
| 순위표 | (10, 94)에서 30px 간격의 4행, 플레이어 행 청록 강조 |
| 코인 | (37, 253)의 별 코인과 잔액 표시 |
| 랩·타이머 | (894, 15)의 기울어진 패널, 스톱워치 아이콘 |
| 미니맵 | 우상단, 실제 코스를 투영한 흰 경로와 체크 깃발 |
| 드리프트 점수 | 우측 중앙, 흰 DRIFT와 노란 +pts, 청록 밑줄 |
| 조향 버튼 | 중심 (81, 616), (213, 616), 반지름 54의 원형 영역 |
| 드리프트 버튼 | 중심 (986, 501), 반지름 49 |
| 부스트 버튼 | 중심 (962, 617), 반지름 53 |
| 속도계 | 중심 (1150, 628), 반지름 124, 청색·적색 개방형 눈금 |
| 니트로 | 하단 (431, 661)~(847, 690), 분할 게이지와 생성형 병 아이콘 |

속도·순위·랩·시간·니트로와 미니맵 마커는 실제 경기에 연결됩니다. 드리프트 점수는 현재 연속 드리프트를 표시하고 잠시 후 사라집니다. 차량 위 순위는 카메라 투영 좌표로 표시하며, 한 바퀴 차이가 나는 차량도 실제 순위로 표시합니다. 기어 표시는 현재 속도를 바탕으로 한 UI 표현입니다. 코인 잔액은 이후 연결할 UI 필드로 현재 기본값은 0입니다.

화면에는 레퍼런스와 같은 조향·드리프트·부스트 버튼을 표시합니다. 감속은 S/↓, 일시정지는 P/Esc 또는 랩·타이머 패널을 사용합니다.

## 시각 검증

```sh
godot --path new --script res://tests/preview_hud.gd
```

`new/docs/hud-preview.png`를 생성합니다. GUI 디스플레이가 필요합니다. UI 변경 후 이 파일을 레퍼런스와 비교할 수 있습니다.

## 생성형 에셋

`assets/ui/`의 니트로 병, 드리프트 차량, 코인은 첨부 레퍼런스를 바탕으로 생성했습니다. 드리프트 아이콘을 재생성하고 가장자리와 창문 표현을 조정했습니다. Godot 가져오기는 256px, 밉맵 사용으로 설정했고, 반투명 여백을 제외해 작은 HUD 슬롯에 맞춥니다. 글꼴은 SIL OFL의 Liberation Sans Bold Italic이며 라이선스는 글꼴과 함께 포함합니다.
