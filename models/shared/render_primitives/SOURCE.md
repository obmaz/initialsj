# 공유 렌더 형상

프로젝트 자체 형상입니다. 미터 UV의 단위 상자, 크기별 쿼드·배기 불꽃, 타이어 자국·충돌 조각·낙석·예고 링·바닥과 HUD RPM 띠를 GLB에 저장합니다. `model.tscn`이 원본을 가져오고 [primitive_assets.gd](../../../scripts/rendering/primitive_assets.gd)가 이름으로 조회합니다.

같은 형상을 공유하고 마지막 게임 씬 종료 시 참조를 해제합니다. 형상을 추가·교체할 때 노드 이름·UV·실척과 효과의 연결점을 함께 검증합니다. 외부 모델·텍스처는 포함하지 않습니다.
