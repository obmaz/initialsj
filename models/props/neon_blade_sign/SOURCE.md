# neon_blade_sign

편집 원본은 [GLB](../../../model_sources/props/neon_blade_sign/model.glb)이며 배포 파일을 직접 수정하지 않습니다. [원본 관리 규칙](../../../model_sources/README.md)을 따릅니다.

프로젝트에서 제작한 홍콩 야시장풍 가상 입체 돌출 간판입니다. 실척 1단위=1m, 정면+Z, 피벗은 바닥입니다. 단일 표면의 형상·법선·접선·UV·UV2·정점색을 GLB에 저장합니다. UV2.x의10은 외벽,20은 세로 간판,2는 발광 띠이며 UV2.y는 정면·후면1, 측면0입니다. 12가지 이미지 변형은 인스턴스 자료로 선택합니다.

생성형 전용 외벽은 [환경 에셋 출처](../../../assets/environment/README.md#홍콩풍-네온-외벽)에 기록했습니다. 기존 게임·도시의 상표나 모델을 복제하지 않았습니다.
