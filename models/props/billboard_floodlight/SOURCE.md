# billboard_floodlight

Initial SJ 자체 제작. [오프라인 도구](../../../tools/author_night_fixtures.py)에서 금속 지주·브래킷·두꺼운 LED 하우징과 렌즈를 제작합니다. 원본은 [편집 GLB](../../../model_sources/props/billboard_floodlight/model.glb)에 보존합니다. 실척은(0.95, 0.63, 1.74)m이며 COLOR.a는0=몸체·1=렌즈입니다. 조립 씬은 정적 형상만 소유하고 발광·실제 광원 예산은 공용 코스 제어기가 관리합니다.
