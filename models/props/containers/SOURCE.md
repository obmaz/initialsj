# containers

현재 형상은 팩의 GLB 원본, 진입점은 [model.tscn](model.tscn)입니다. 치수·피벗·UV와 움직이는 부품의 연결점은 [모델 계약](../../../docs/MODEL_PIPELINE.md)을 따릅니다.

40피트 컨테이너의 실제 치수2.44×2.59×12.19m를 기준으로 직접 작성한 형상입니다. 철판 골과 두께16cm의 모서리 프레임을 실제 메시로 만듭니다. 측면·쌍여닫이문·지붕은 면별 UV로 구분합니다.

전용 재질은 공용 생성형 이미지 `assets/environment/harbor-cargo-surfaces.png`를 참조합니다.2026-11-11 이미지 생성 도구로 만든 가상의 TIDEMARK·NORTHWAKE·PORTLINE 세 가지 도색이며 원본 생성 결과를 편집 없이 복사했습니다. 실재 운송업체의 상표는 사용하지 않습니다. 형상과 면별 UV는 GLB에 저장하며 제작 계약은 [모델 제작 지침](../../../docs/MODEL_PIPELINE.md)을 따릅니다.
