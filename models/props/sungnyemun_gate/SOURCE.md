# sungnyemun_gate

Initial SJ 자체 제작 GLB. 실척56×32×16m이며 숭례문을 참고한 게임용 해석입니다. 도로 중앙의 통과 공간과 전체 실척은 유지합니다. 지붕의 용마루는 긴 가로 축에 놓고 앞뒤 경사·들린 처마를 입체로 만듭니다. 이전 원본은 형상 재생성 전에 SHA-256별로 백업합니다. 원본은 [model_sources](../../../model_sources/props/sungnyemun_gate/model.glb)에 있습니다.

[형상 제작 도구](../../../tools/bake_seoul_landmarks.py)가 기본 형상을 만들며 [전용 UV 도구](../../../tools/texture_sungnyemun.py)는 기존 원본을 SHA-256별로 백업한 뒤 UV0·UV1만 추가합니다. 의도적으로 형상을 재생성하면 UV 도구와 모델 최적화·임포트를 다시 실행합니다. 팩의 전용 재질·이미지를 기본 정점색 재질로 덮어쓰지 않습니다.

`heritage_atlas.png`는2026-11-12 OpenAI 이미지 생성 도구로 제작한 전용 석재·기와·단청 자료입니다. 외부 사진·글자·로고를 사용하지 않습니다. 왼쪽 절반은 화강석, 오른쪽 위는 기와, 오른쪽 아래는 단청입니다. UV0는 면 방향별 반복 좌표, UV1.x는0=석재·1=기와·2=단청이며 `facade.gdshader`가 경계 여백과 밉맵 미분을 적용합니다.1536×1024px 이미지1장과 불투명 재질1개를 사용합니다.
