# 대형 경기장 관중석 모듈

`stadium_grandstand`는 미터 단위의 절차적 모델입니다. 정면은+Z, 계단식 좌석은-Z로 올라가며, 좌석 폭74m(지붕76m)·깊이70.76m·64개 좌석 열·세 단의 관람 데크·상부 운영실·후면 지주·난간을 한 메시로 만듭니다. 전체 높이는51.35m입니다. 코스 배치·광원·물리·애니메이션은 팩에 포함하지 않습니다.

`crowd.png`는 image_gen.imagegen 생성 원본 `exec-fc615c4e-390f-4f13-8443-e04b98d927f9.png`를 편집 없이 복사한1254×1254 관중·좌석 재질입니다. 촘촘한 성인 관중, 수평 좌석 열, 자연스러운 의복 색상, 균일 주광, 무문자·무상표·반복 표면을 요청했습니다. 외부 사진을 입력하지 않았으며 원본은 `/workspace/generated_images/`에 보존합니다. 실제 좌석 상판·정면의 전용 UV와 인스턴스별 위상으로 사용하고 통로는 비웁니다. 이미지의 인물은 실제 동작하는 캐릭터가 아닙니다.

경기장 중앙과 양 끝의 크기 차이를 표현하는 배치에는0.62~1.08의 균일 배율을 허용합니다. 가장 작은 관중석도 높이 약32m이며, 배치와 기초는 실제 변환된 모델 외곽에 맞춥니다.
