# billboard

편집 원본은 [원본 GLB](../../../model_sources/props/billboard/model.glb)이며, 이 팩의 GLB는 재생성되는 배포 파일입니다. 원본을 삭제하거나 배포 GLB를 직접 수정하지 않습니다. 진입점은 [model.tscn](model.tscn)입니다. 치수·피벗·UV와 움직이는 부품의 연결점은 [모델 계약](../../../docs/MODEL_PIPELINE.md)을 따릅니다.

프로젝트에서 직접 제작해 GLB로 저장한 형상입니다. 단위와 제작 인터페이스는 [모델 제작 지침](../../../docs/MODEL_PIPELINE.md)을 따릅니다.

광고 패널은0.9m 템플릿 두께의 밀폐 뒤판·입체 테두리·뒤쪽 가로보·확대 지주·콘크리트 기초를 사용합니다. 인쇄면은 뒤판 앞쪽에 별도로 둡니다. 최종 미터 치수는 정의의 배율을 적용합니다.

[야간 등기구 저작 도구](../../../tools/author_night_fixtures.py)는 패널 양면에 투광등4개를 추가합니다. 기존 인쇄 UV·정점 속성·인덱스를 보존하고 UV1.x의−2는 금속 몸체,−3은 발광 렌즈를 뜻합니다. 등기구는 기존 가로·깊이 경계 안에 넣어 레일과 광고의 안전 간격을 유지합니다. 자체 제작 추가 형상은 `fixture_schema=2`로 표시하며 재실행 시 중복 추가하지 않습니다.
