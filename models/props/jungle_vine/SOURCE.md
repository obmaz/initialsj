# 정글 늘어진 덩굴

프로젝트에서 직접 만든 미터 단위 절차 형상입니다. 서로 다른 곡선을 따라 내려오는 두께 있는 줄기4개와 고정된3D 방향의 잎 무리를 사용합니다. 원점은 지면이며 윗부분은12m입니다. 카메라를 향해 회전하지 않으며 광원·물리·주행 스크립트가 없습니다.

잎과 껍질은 사용자 소유 SJRPG에서 가져온 기존 생성형 재질을 공유합니다. 생성 프롬프트·원본·라이선스는 [공유 식생 출처](../../shared/foliage/SOURCE.md)가 정본입니다. 새 이미지 복사본을 만들지 않고 알파 시저로 잎 사이의 빈틈을 보존합니다. 정글 도로와 터널 입구의 구체 배치는 통합 환경이 담당합니다.
