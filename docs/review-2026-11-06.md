# Code review and regression fixes — 2026-11-06

Reviewed shared driving, CPU surface contact, jumping, collision clearance, adaptive render quality, mobile hit areas, and the replacement second circuit. Godot 4.7.2 is pinned in both CI and export.

| Priority | Reproduced defect | Fix |
| --- | --- | --- |
| P2 | A CPU car landing beyond a puddle swept its entire airborne path against the ground and incorrectly became wet. | Player and CPU ground contact require a wholly grounded frame, including no launch/landing events. A grounded control still hits the puddle. |
| P2 | Jump collision compared relative jump heights while ignoring road elevation. A nearby car on an incline could incorrectly hit or pass through another car. | Both the actual driving step and contact helper compare world road height plus airborne height. Near-miss clearance uses the same world heights. |
| P3 | AUTO quality retained a slow window across pausing. A single new slow window could prematurely degrade quality. | Invalid/paused samples clear the consecutive-window counter; changing quality resets the wall clock. |
| P3 | AUTO quality discarded every foreground frame over 0.5 seconds, leaving a very slow game unable to reduce quality. | Actual foreground racing frames are counted, including one-second frames. Paused/background state still resets sampling. |
| P3 | The speedway start line covered only18m of its29m road. | One joined checker mesh spans every lane and supports banked surfaces;36 separate box submissions become one. |
| P3 | The pause glyph's touch box was below a 44px mobile target at 414px landscape height. | Expand its hit area to 90×84 design pixels (about52×48 screen pixels), retaining the existing visual layout. |

Additional independent review found floating speedway stands above the outer bank and a browser Forward/BFCache re-entry bounce. The outer bank now has a continuous platform and supported grandstand foundations. The history bridge distinguishes Back from Forward and has a leave→Forward→Back regression.

Nine assertions reproduced the original collision/CPU/quality/touch defects before correction. The dedicated regression checks pass after correction; the actual collision step and grounded control are tested, not only helper calculations. A suspected traffic interpolation issue could not be reproduced and was not changed.

The second review also caught a new bank transition that changed too sharply (0.016rad/m). A circular weighted smoothing filter reduces the measured maximum to0.00523rad/m, while maintaining a 25.72° maximum bank and a flat back straight. The inner bank edge stays above the infield; each lane and the roll profile close continuously.

Evidence: [regression metrics](review-regression-metrics.json), [course geometry](speedway-course-metrics.json), [three-car drive](speedway-drive-metrics.json), and [world-space contact checks](contact-metrics.json). Native visual checks use GL Compatibility/Mesa llvmpipe; these are not claims about Android hardware FPS.

Unused old 2D tree/landmark/urban cutouts and their historical Fuji backdrop script remain in source for reference but are excluded from the Web pack. Active foreground models and the urban skyline are solid3D; the compiled pack is checked independently after export.
