# Godot 4.7.2 전환

실제 실행 엔진은 `4.7.2.stable.official.ed1daf0bf`입니다. 프로젝트 기능 버전을4.7로 올리고 `.godot-version`에4.7.2를 고정했습니다. 로컬 실행기 `tools/godot`과 CI가 같은 파일을 읽으며, `tests/verify_engine.gd`가 실제 엔진 버전과 비교해 불일치를 거부합니다.

[공식 릴리스](https://github.com/godotengine/godot-builds/releases/tag/4.7.2-stable)에서 Linux 실행 파일과 표준 내보내기 템플릿을 받았습니다. 두 아카이브의 SHA256이 공식 릴리스 메타데이터와 일치하는지 확인한 뒤 설치했습니다. 내보낸 `index.wasm`은 검증된4.7.2의 `web_nothreads_release.zip` 안 WASM과 바이트 단위로 일치합니다. 엔진 실행 파일과 Web 런타임을 함께 교체했습니다.

- 실제 엔진 버전 검사와 프로젝트 가져오기, 전체 주행 규칙 검사 통과
- 후지 차량3대의3랩 완주, TOUR 숙련 조작5가지 완주와 가속만 유지한 주행의 실패 확인
- 실제 그래픽 화면에서 메인·설정·코스·차량·출발 전환과 터치 영역 검사 통과
- 파일 효과음 검사: 클리핑0프레임, 음소거 뒤 RMS0
- 단일 스레드 Web release 내보내기, 가로 모드 PWA manifest 검사 통과
- 내보낸 PCK를 별도 프로젝트에서 불러와 TOUR·후지 가드레일과 흙 갓길 감속 확인

[버전·해시·검사 데이터](godot-4.7.2-metrics.json)를 함께 보관합니다. 가드레일·갓길 수정도 같은4.7.2 빌드에 포함합니다. 서초 전용 개발 변경은 제외했습니다. 실제 휴대폰 브라우저의 프레임률을 측정한 결과는 아닙니다.
