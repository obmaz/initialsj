# UI 구현 경계와 인수인계

## 현재 화면 기준

시작·홈(모드 선택)·트랙 선택·차량 선택·설정은 [해안 원화](../art_sources/ui/coastal/README.md)를 실제 픽셀로 사용합니다. 차량 선택 마스터와 같은 환경판에서 헤더·일반 버튼·주버튼·패널을 재단하고, 기존 HUD 입력 Rect에 맞춰 다섯 통이미지로 조립합니다. [베이크 자료](../art_sources/ui/coastal/layout.json)의 화면별 이미지가 배치 비교의 기준이며, 생성 마스터 원본의 전체 구도를 입력 위치로 간주하지 않습니다.

구현·수용기준은 [원화 통합 계획](PRE_RACE_ART_PLAN.md)과 [디자인 계약](PRE_RACE_ART_DIRECTION.md)을 따릅니다. 부트·긴 로딩에는 `start.png`를 사용하고 준비 후 기존 메뉴로 자동 진입합니다. 메뉴와 일시정지에서 여는 설정은 같은 밝은 화면을 사용합니다. 주행 HUD·결과·일시정지 자체는 기존 스타일을 유지하며 별도의 밝은/네온 선택 옵션은 제공하지 않습니다.

글자·브랜드·차량·성능·설정 값은 이미지에 굽지 않습니다. 메뉴는 실제 Label 풀과 번역 키를 사용하고 선택 차량은 실제 GLB·튜닝값을 표시합니다. 같은 1280×720 안전 영역 변환으로 배경·텍스트·입력을 맞추며, 공용 설정의 모달에도 같은 변환을 적용합니다.

현재 통이미지 한 장만 미리 읽고 공용 부품·코스 아틀라스를 공유합니다. 이전 통이미지는 직전 그리기 명령 교체 뒤 놓고, 주행 진입 때 메뉴 참조와 미리 읽기를 비웁니다. 원본은 `art_sources/ui/coastal/`, 배포 아트는 `assets/ui/pre_race/`에 둡니다. 원본 폴더는 엔진 가져오기·제품 내보내기에서 제외합니다. 대체된 옛 이미지의 원본 보관 위치와 실제 사용 아트는 [아트 출처](../assets/ui/GENERATED_ART.md)를 따릅니다.

## 구현 경계

- [공통 스타일](../scripts/rendering/neon_style.gd): 트랙 5개와 투어 15지역에 명시적 색을 둡니다. 기존 보조광 색과 코스 인스턴스 노면의 약한 프레넬 색만 조정합니다. 주광·보조광의 에너지, 그림자와 광원 수는 기존 주야간·날씨 정책을 유지합니다. `world_assets.finish()`가 분리한 실제 노면·진입 노면에 적용하므로 준비된 분기도 같은 경로를 씁니다. 공통 asphalt는 이전부터 여러 트랙·투어가 공유하던 셰이더이며 Fuji 전용이 아닙니다.
- [차량 외곽선](../shaders/vehicle_outline.gdshader): 편집 GLB와 메시를 바꾸지 않고 외피·윙에 공유 inverted-hull overlay를 씁니다. 적용 대상은 플레이어와 쇼룸입니다. 상대와 투어 교통 차량은 `traffic=true`이므로 제외합니다. 유리·휠·배기구에도 패스를 추가하지 않습니다. detail 거리가 45m 이상이면 제거하며, 튜닝·보호색·오픈카 외피 교체는 기존 노드를 사용합니다. 마지막 렌더 자원 소유자가 나가면 캐시를 해제합니다.
- [조작 배치](../scripts/input/touch_layout.gd): 조향 좌우·3단계 크기·자동 가속을 조합한 12가지 배치를 지원합니다. 현재 조합 하나만 캐시하고 설정을 바꿀 때 다시 계산합니다. 표시·터치·읽기 전용 웹 진단은 같은 Rect를 사용합니다. 가까운 버튼 하나가 포인터를 소유하고, 여러 손가락은 독립적으로 처리합니다. 자유 드래그 대신 안전 영역과 버튼 간격을 검증한 프리셋을 제공합니다.
- [조작 설정 화면](../scripts/ui/touch_layout_panel.gd): 설정의 CONTROLS에서 좌우·크기·초기화·미리보기를 제공합니다. 닫기는 부모 설정으로 한 단계 돌아갑니다. 패드 입력도 같은 기능을 사용합니다. 기존 저장 파일에는 기본 배치가 적용되고, 잘못된 값은 기본값으로 복원합니다.
- [모달 연출](../scripts/ui/modal_motion.gd): 설정·조작 설정·일시정지·결과 카드가 0.18초 동안 96.5%에서 원래 크기로 나타나고, 닫기는 0.12초를 사용합니다. 새 알파 페이드는 추가하지 않습니다. 기존 전체 화면 전환은 별도로 유지합니다. 카드와 풀 Label은 같은 변환을 쓰며 입력은 역변환합니다. 닫힘 중 새 입력을 막고, 화면 교체 시 이전 콜백을 취소합니다. 모션 감소는 즉시 전환하며 노드·타이머를 매번 만들지 않습니다. 3D 중계 장면 자체에는 변환을 적용하지 않습니다.

## 주행 UI와 이번 작업의 경계

투어·트랙 미니맵은 [공통 HUD 배치](../scripts/ui/race_hud_layout.gd)의 같은 위치·크기를 사용하며 배경·외곽 테두리는 그리지 않습니다. 경로·마커에 어두운 외곽선을 두어 명암 대비를 유지합니다. 상단 카드의 기본 바깥 여백은24px이고 속도계는 좌측의 작은 숫자·기어·RPM 표시입니다. 가상 조이스틱의 기본 반경은90px, 이동은72px, 조이스틱·페달 중심은 y620, 기본 바깥 여백은90px입니다. 상단 HUD 배경은60% 불투명도의 남색을 사용합니다.

설정의 음악·효과음은 각각70·50을 기본으로0~100 값을 독립 저장합니다. 차량별 일반/툰·강도는 튜닝 저장값을 사용하고 새 선택의 기본은 일반 모드입니다. 주행의 블러·방사형 선·블러 아이템은 제공하지 않습니다. 이 기능들의 주행·저장 계약을 시작 전 원화 교체로 바꾸지 않습니다. 고스트와 원경 품질·거리 LOD도 이번 원화 통합의 변경 범위가 아닙니다.

## 검증과 전달

독립 검증자는 이번 원화 통합 전체에 최대5회 검토합니다. 화면마다 예산을 다시 시작하지 않으며, 실제 후보·원화 해시·캡처·입력 증거·판정은 `build/reports/pre-race-art/`에 기록합니다. 이 문서 자체를 검증 완료나 실기기 성능의 근거로 사용하지 않습니다.

원화·입력·번역·수명은 [시작 전 원화 검사](../tests/pre_race_art_checks.gd)와 기존 모바일·메뉴 회귀 검사로 확인합니다. [기존 네온 기능 검사](UI_OVERHAUL_PLAN.md)는 주행 스타일·외곽선·조작·모달의 기능별 계약 참고이며, 현재 원화 작업의 검증 횟수는 이 문서와 새 계획의 전체5회 기준을 따릅니다. 같은 후보의 폰·폴드 화면을 베이크 이미지와 정렬해 비교하고 실제 터치·Back·선택·저장을 확인합니다.

엔진·로컬 검사의 정본은 [개발 안내](DEVELOPMENT.md)입니다. `python3 tools/check.py`와 필요한 실제 화면 검사를 통과한 소스를 푸시하며, [APK 전달 스킬](../.agents/skills/dropbox-apk/SKILL.md)에 따라 Dropbox 최신 기록에서 다음 번호를 정해 배포합니다. 대상 없는 배포는 Dropbox APK 전달이며 웹 게시·태그·공개 릴리스는 추가하지 않습니다. 브라우저·패키지 검증과 Android 실기기 실행·성능 측정은 구분해 보고합니다.
