# 네온 UI 후속 개발 인수인계

## 기준과 통합

사용자 결정에 따라 `experiment/modern-ui-track01`의 네온 UI를 main에 통합합니다. 밝은/네온 테마 선택 옵션은 추가하지 않습니다. 기존 브랜치의 라운드별 승인·60fps·웹 배포 주장은 측정 근거와 구분합니다. 게임의 실제 상태·저장·입력·Android 빌드 계약은 [AGENTS.md](../AGENTS.md)와 [개발 안내](DEVELOPMENT.md)를 따릅니다.

## 구현 경계

- [공통 스타일](../scripts/rendering/neon_style.gd): 트랙 5개와 투어 15지역에 명시적 색을 둡니다. 기존 보조광 색과 코스 인스턴스 노면의 약한 프레넬 색만 조정합니다. 주광·보조광의 에너지, 그림자와 광원 수는 기존 주야간·날씨 정책을 유지합니다. `world_assets.finish()`가 분리한 실제 노면·진입 노면에 적용하므로 준비된 분기도 같은 경로를 씁니다. 공통 asphalt는 이전부터 여러 트랙·투어가 공유하던 셰이더이며 Fuji 전용이 아닙니다.
- [차량 외곽선](../shaders/vehicle_outline.gdshader): 편집 GLB와 메시를 바꾸지 않고 외피·윙에 공유 inverted-hull overlay를 씁니다. 적용 대상은 플레이어와 쇼룸입니다. 상대와 투어 교통 차량은 `traffic=true`이므로 제외합니다. 유리·휠·배기구에도 패스를 추가하지 않습니다. detail 거리가 45m 이상이면 제거하며, 튜닝·보호색·오픈카 외피 교체는 기존 노드를 사용합니다. 마지막 렌더 자원 소유자가 나가면 캐시를 해제합니다.
- [조작 배치](../scripts/input/touch_layout.gd): 조향 좌우·3단계 크기·자동 가속을 조합한 12가지 배치를 지원합니다. 현재 조합 하나만 캐시하고 설정을 바꿀 때 다시 계산합니다. 표시·터치·읽기 전용 웹 진단은 같은 Rect를 사용합니다. 가까운 버튼 하나가 포인터를 소유하고, 여러 손가락은 독립적으로 처리합니다. 자유 드래그 대신 안전 영역과 버튼 간격을 검증한 프리셋을 제공합니다.
- [조작 설정 화면](../scripts/ui/touch_layout_panel.gd): 설정의 CONTROLS에서 좌우·크기·초기화·미리보기를 제공합니다. 닫기는 부모 설정으로 한 단계 돌아갑니다. 패드 입력도 같은 기능을 사용합니다. 기존 저장 파일에는 기본 배치가 적용되고, 잘못된 값은 기본값으로 복원합니다.
- [모달 연출](../scripts/ui/modal_motion.gd): 설정·조작 설정·일시정지·결과 카드가 0.18초 동안 96.5%에서 원래 크기로 나타나고, 닫기는 0.12초를 사용합니다. 새 알파 페이드는 추가하지 않습니다. 기존 전체 화면 전환은 별도로 유지합니다. 카드와 풀 Label은 같은 변환을 쓰며 입력은 역변환합니다. 닫힘 중 새 입력을 막고, 화면 교체 시 이전 콜백을 취소합니다. 모션 감소는 즉시 전환하며 노드·타이머를 매번 만들지 않습니다. 3D 중계 장면 자체에는 변환을 적용하지 않습니다.

## 검증과 자료

[후속 기능 검증 계획](UI_OVERHAUL_PLAN.md)에 기능별 계약을 정리합니다. 실제 실행 로그·스크린샷·검증자 회차 기록은 Git에서 제외한 `build/reports/`에 둡니다. 검증자는 기능마다 최대 3회까지 검토합니다. 측정 없이 60fps나 실기기 성능 개선을 단정하지 않습니다.

이전 문서가 가리킨 `generated_images/concept_*.jpg` 네 원화는 저장소에서 추적되지 않습니다. 해당 파일을 확보하기 전에는 원화와 완전히 일치한다고 보고하지 않습니다. 새 UI 글자는 번역 가능한 텍스트로 유지하며 [메뉴 번역 원문](../localization/menus.pot)에 등록합니다.

엔진은 Godot **4.7.2**, 실행 진입점은 `./tools/godot`입니다. 웹 화면 검사에는 로컬 Web export와 `python3 -m http.server --directory build/site`를 사용할 수 있습니다. `build/serve.py`나 특정 PC의 Godot 경로는 저장소 계약이 아닙니다. 웹 게시와 APK 배포는 사용자 요청에 따라 [APK 전달 스킬](../.agents/skills/dropbox-apk/SKILL.md)을 적용합니다.
