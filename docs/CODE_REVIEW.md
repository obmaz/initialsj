# 현재 검토 범위

## 트랙 1의 월드 주행 변경

FUJI LAKESIDE는 약 5.721km, 고저차 약 60.8m, 최대 뱅킹 약 11.82도의 코스입니다. 실제 위·아래 도로의 교차 높이 차이는 약 35.02m입니다. [world_car.gd](../scripts/world_car.gd)의 `CharacterBody3D`가 실제 차체 방향으로 움직이고, [fuji_collision.gd](../scripts/fuji_collision.gd)가 노면·장벽의 오목 삼각형 충돌체를 구성합니다. 도로 거리·차선 계측은 주행 몸체를 강제로 옮기는 용도로 사용하지 않습니다.

[circuit_progress.gd](../scripts/circuit_progress.gd)는 12개 순차 게이트와 3랩을 검증합니다. 정지 상태의 브레이크 유지로 후진을 지원합니다. 투어와 SUNCOAST의 기존 컨트롤러는 별도로 유지합니다. 검토 대상은 실제 물리 프레임에서의 접지·조향·높이별 교차·장벽·후진·경기 진행이며, 차량 3대의 연속 주행은 고정 프레임 조건에서 별도로 확인합니다.

갓길 복귀 중 낮은 노면 경계에 걸리던 문제는 실제 상·전방·하방 충돌 검사로 최대 22cm 단차만 넘도록 수정했습니다. 넓은 합법 갓길에서 진행도가 멈추는 문제와 무효 게이트 통과 후 랩이 영구 정지하는 문제도 수정했습니다. 무효 통과는 보상하지 않고 같은 게이트를 다음 바퀴에 다시 통과하도록 합니다. CPU는 빈 차선을 판단하며, 정체 시 후방 공간이 있을 때만 짧게 후진합니다. 교량 아래 차량은 상부의 회피·추월 보상에 영향을 주지 않습니다.

## 트랙 2의 고저차와 노면 가속

SUNCOAST에 약 36m 고저차와 좌우 교대 패드 두 묶음(각 6개), 부스트 레인 두 곳을 추가했습니다. 레인은 지상 위치를 매 프레임 확인하며, 이탈·공중·제동·충돌 시 효과를 해제합니다. 패드와 달리 지속 시간이나 진입 보상을 적립하지 않습니다. 새 검사로 세 차량의 실제 조향 연속 획득, 레인 가속·이탈, 공중 통과와 움직임 줄이기 표시를 확인합니다. 지형·시설물의 실제 높이와 3랩 주행도 검사합니다.

## 코너 주행 저항

플레이어와 CPU에 공통 타이어 저항을 적용했습니다. 조향 없는 직진·공중·정지 조향에는 코너 손실이 없고, 실제 회전·속도·슬립·접지력과 뱅킹에 따라 저항을 계산합니다. 최고속도 근처에서는 엔진 여유 힘도 함께 계산해 감속이 곧바로 상쇄되는 문제를 막습니다. 부스트 종료 후 기본 속도로 돌아오는 제동은 별도로 유지합니다. 세 차량의 직선·완만/급커브·부스트·제동·공중·재가속을 같은 입력 조건으로 검사하며 기록은 새 물리 버전별로 분리합니다.

일반 가속력을 약 18% 낮추고 타이어 저항을 강화했습니다. 투어·SUNCOAST는 실제 차선 횡이동과 횡가속도 엔진 부하와 감속에 반영합니다. 최고속도·부스트 가속·제동은 유지하며, 직선 차선 변경과 공중 조향을 회귀 검사에 추가했습니다. 느려진 출발에서 니트로 대기 입력이 실제 활성화 속도에 도달하면 한 번만 소비되는지도 확인합니다.

## 투어 밀도와 분기 시야

15개 지역의 복수 능선·기믹과 입구/출구 높이 연속성을 검사합니다. 체크포인트 직선은 420m로 줄이되 최고 부스트에서도 3초 이상 선택 여유를 남깁니다. 시작62초/보상46~52초 조건에서 모든 차량과 좌·우·혼합 경로를 완주 검사합니다. 작은 한 줄 선택 카드와 별도 터치 여백으로 도로 시야를 확보하며, 짧아진 점프는 프레임 간격·실제 출발 경사·착지/터널 간격을 확인합니다.

## 충돌·차량 복구·전체화면

고속 조향 응답을 완화하고, 접촉 방향의 반발 속도가 반복 접촉 처리에서 지워지지 않게 했습니다. 강한 가드레일 충돌은 실제 공중 이동과 차체 중심 회전을 적용하며, 얕은 스침·노면 경계·일반 차량 접촉은 전복에서 제외합니다. 실제 터널 천장으로 충돌 카메라 차단도 확인합니다. 4초 동안 수평 3m를 벗어나지 못하면 복구 버튼이 나오며, 빈 노면 탐색과 시간·랩·게이트·사용한 점프대 기록 보존을 검사합니다.

설정의 전체화면은 실제 DOM 사용자 입력으로 진입·종료하고 설치 manifest는 fullscreen을 사용합니다. 전체화면 종료와 Back 중복 이벤트가 레이스를 즉시 재개하지 않도록 검사합니다.

## 저장소 정리

실제 게임 진입점에서 도달하는 소스·에셋과 유지하는 검사 도구를 기준으로 저장소를 정리합니다. 과거 구현 전용 코드, 중복 미리보기, 오래된 리뷰·스크린샷·수치 보고서는 제거하며 변경 이력은 Git에서 확인합니다. 제품 규칙과 개발 명령은 [GAMEPLAY.md](GAMEPLAY.md)와 [DEVELOPMENT.md](DEVELOPMENT.md)로 통합합니다.

실행 중인 3D 전경과 관계없는 이전 2D 오브젝트·도시 이미지 및 전용 카탈로그를 제거하고, 불필요한 HUD 필드·리소스와 오래된 주석을 정리합니다. 이후 다시 쌓이지 않도록 [저장소 검사기](../tools/verify_repository.py)로 참조·사이드카·문서 링크를 검증합니다. 검사 산출물은 `build/reports/`에만 생성합니다.

로딩·홈·차고·두 코스의 생성형 아트를 현재 차량·지역 콘셉트로 갱신합니다. 차고와 주행 차량은 계속 같은 3D 모델을 사용합니다. 충돌 피드백은 강도·방향에 따라 짧게 반응하고, 정지·미세 접촉에서는 과한 이펙트를 억제합니다. 고정 풀을 재사용하고 움직임 줄이기에서는 카메라·차체 진동과 파편을 생략합니다.

## 유지하는 회귀 검사

| 범위 | 확인하는 동작 |
| --- | --- |
| 경기 진행·입력 | 시간 만료 전 체크포인트·종료 처리, 포커스·회전·정지, 중복 화면 이동 |
| 차량·니트로 | 서로 다른 능력, 세 자원 방식, 새 누름 감지, 취소·회복·기록 분리 |
| 충돌·피드백 | 방향별 차체 겹침 해소, 경사와 공중 높이, 강도별 반동·입자 상한·재시작 초기화 |
| CPU·노면·점프 | 앞차·차선 안전, 지상 노면 효과, 공중 통과 후 착지, 중복 패드 소비 방지 |
| 투어·터널 | 직선 안내 시간, 터치 선택·수동 우선, 표지판 벽 간격, 제한된 조명·숨겨진 렌더 준비 |
| 배경·서킷 | 실제 3D 모델과 도로 간격, 지역 다양성, 순차 게이트·랩, 높이별 교차·물리 접지, 뱅킹과 관중석 기초 |
| 웹·품질 | 설치 안내, Back·Forward history, 중단 시 품질 표본 초기화와 느린 프레임 대응 |

기본 검토 명령은 다음과 같습니다.

```sh
python3 tools/verify_repository.py
./tools/godot --headless --path . --editor --import --quit
./tools/godot --headless --fixed-fps 60 --path . --script res://tests/race_test.gd
node tests/install_bridge_review.cjs
node tests/back_bridge_review.cjs
```

시각·오디오·긴 주행 검사는 해당 변경에 맞춰 별도로 실행합니다. 결과는 실행 시 생성하는 보고서와 CI 로그에서 확인합니다. 과거 날짜의 성공 수치나 캡처를 현재 빌드 검증으로 대신하지 않습니다. 네이티브·모의 브라우저 검사는 실제 안드로이드 기기의 프레임률을 보장하지 않습니다.
