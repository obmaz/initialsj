# 튜닝샵

차고의 `TUNING` 버튼, 키보드 `T`, 패드 방향키 위로 튜닝샵을 엽니다. 버튼에는 단축키를 병기하지 않습니다. 선택 차량 한 대를 독립 3D 뷰포트에 표시하며 드래그 회전·전면/측면/후면 시점·부스트 시연을 제공합니다. 투어와 트랙은 같은 저장값과 조립 어댑터를 사용합니다.

생성형 디자인 시안을 기준으로 밝은 해안 작업장·흰색 패널·청록 선택 상태·노란 적용 버튼을 사용합니다. 위쪽4개 탭, 왼쪽 옵션, 오른쪽 투명3D 미리보기, 아래쪽 작업 버튼으로 구성하며 [tuning_theme.gd](../scripts/ui/tuning/tuning_theme.gd)가 서체·색·포커스·선택 상태를 소유합니다. 생성형 배경과 실제 컨트롤을 구분하고 긴 요약 열을 따로 두지 않습니다. 출처는 [UI 이미지 출처](../assets/ui/GENERATED_ART.md)를 따릅니다.

## 선택과 적용

| 탭 | 현재 선택 |
| --- | --- |
| 도장 | 차체·보조 색상 팔레트와 사용자 지정 선택기, 유광·무광·메탈릭 |
| 리버리 | 순정과 차종별 헤리티지 스트라이프·해안 웨이브·서킷 그래픽3종, 총12종의 생성형 이미지 |
| 휠 | 순정·5스포크·분할 스포크와 림 색상 |
| 리어윙 | 순정·덕테일·GT 윙·윙 없음 |

작업 중 조합은 미리보기에만 반영합니다. `COMPARE`는 마지막 적용값을 보여 주고, `RESET`은 작업 중 조합만 순정으로 되돌립니다. `APPLY`가 성공해야 저장값과 실제 주행차·차고 미리보기가 함께 바뀝니다. 변경이 없으면 적용 버튼을 비활성화하며 저장 실패 시 편집값을 유지하고 오류를 표시합니다. `CANCEL`·차고로 돌아가기·뒤로가기는 미적용 변경 확인 창을 거쳐 닫습니다. 색상 선택 창이나 확인 창이 열려 있으면 뒤로가기는 해당 창부터 닫습니다.

외형 선택은 차량별로 저장합니다. 최고속도·가속·제동·그립·충돌체·휠 반경·휠베이스·접지 중심은 바꾸지 않습니다. 기존 투어 도장 해금과 번호판은 [tour_passport.gd](../scripts/race/tour_passport.gd)가 계속 소유하며, 별도 튜닝이 없는 차량은 기존 도장 선택으로 초기화합니다. 차고의 도장 버튼은 저장된 튜닝의 다른 부품을 유지하고 도장색만 변경합니다.

차고 도장 표시는 실제 선택을 따라 `ORIGINAL`·보상 색상·`CUSTOM`으로 구분하고 기본 번호판은 `STANDARD`로 표시합니다. 보상 선택은 구현된 기능이며, 다른 보상이 아직 없다면 투어 도착지 해금 안내를 표시합니다. 샵의 사용자 지정 도장은 투어 해금과 관계없이 사용할 수 있습니다.

## 소유권과 저장

- [customization_store.gd](../scripts/vehicles/customization_store.gd)는 `user://vehicle_customization.cfg`의 스키마2과 차량 ID별 선택을 소유합니다. ID는 `nimori`·`veltrix`·`ironvale`·`straud`입니다. 임의 파일 경로 대신 검증한 선택 번호·색상만 저장합니다.
- 적용 시 임시 파일을 쓴 뒤 원본으로 교체합니다. 성공한 뒤에만 메모리의 저장값을 교체합니다. 잘못된 색·선택 번호는 순정값으로 제한하고 알 수 없는 미래 스키마는 덮어쓰지 않습니다. 기존 완주·해금·번호판 기록은 삭제하지 않습니다.
- [vehicle_customization.gd](../scripts/vehicles/vehicle_customization.gd)는 같은 선택을 주행차·차고·샵 미리보기에 적용합니다. 색 변경은 기존 재질의 유니폼만 갱신하고 휠·윙 종류가 바뀔 때만 노드를 교체합니다.
- [tuning_shop.gd](../scripts/ui/tuning/tuning_shop.gd)는 편집값·비교·확인 창과 단일 미리보기를 소유합니다. 샵이 열려 있을 때 기존 차고의 키보드·패드·터치 동작을 실행하지 않습니다.

## 도장면·리버리 계약

현재 네 차량의 원본 GLB는 실제 표시용 `PaintShell`·`TrimShell`을 갖습니다. 도장면의 UV0는 텍스처 좌표이며 유리·램프·트림의 기존 정점색·금속성·거칠기·발광 자료는 보존합니다. 면을 중복으로 겹쳐 그리지 않습니다. 차량별 `livery-uv.json`은 초기 전개 범위와 도장 삼각형 수를 기록합니다.

기존 `BodyShell` 전체 메시도 읽기 전용 호환 형상으로 보존합니다. 이미 직렬화된 투어 교통 차량이 이 메시 경로를 참조하기 때문입니다. [vehicle_models.gd](../models/vehicle_models.gd)는 플레이어 차량에서 이 전체 메시를 표시하지 않고 분리된 두 메시만 그립니다. 일반 교통 차량은 기존 전체 차체와 공유 메시 경로를 유지합니다.

[vehicle_livery.gdshader](../shaders/vehicle_livery.gdshader)는 기본 도장색·생성형 그래픽·보조색과 마감을 합성합니다. 하나의 [아틀라스](../models/shared/vehicle_liveries/atlas.png)에서 차종과 스타일에 맞는 셀을 선택합니다. 검은 부분은 기본 도장색을 보여 주고 셀 경계에는 샘플링 여백을 둡니다. 출처·배열은 [전용 이미지 출처](../models/shared/vehicle_liveries/SOURCE.md)에 기록합니다. 리스폰 보호 재질은 새 도장·휠 셰이더도 복제하며 종료 시 원래 재질로 되돌립니다.

## 휠·윙 팩과 원본 보호

독립 부품은 `models/vehicle_parts/<id>/`의 `definition.tres`·`model.glb`·`model.tscn`·`SOURCE.md`가 소유합니다. [모델 카탈로그](../models/model_catalog.gd)가 정의를 자동 탐색하며 편집 원본은 `model_sources/vehicle_parts/<id>/model.glb`에 보존합니다. 현재 ID는 `five_spoke`, `split_spoke`, `ducktail`, `gt_wing`입니다.

휠은 기존 타이어·피벗을 유지하고 로컬+Y 축의 바깥쪽에 GLB 림을 장착합니다. 교체 시 기존 림 표면만 셰이더로 제외합니다. 네 바퀴는 같은 림 메시를 공유하고 실제 타이어 외경·폭·접지 계산은 그대로 둡니다. 윙은 기존 장착 원점·차량 폭에 맞추며 기존 가동 에어로의 부스트 이동·복귀를 사용합니다. 윙 없음은 가동 참조를 안전하게 해제합니다.

[오프라인 제작 도구](../tools/bake_tuning_models.py)는 기존 도장면 분리가 있으면 다시 덮어쓰지 않고, 기존 부품 원본도 기본 실행에서는 보존합니다. 의도적으로 자체 제작 부품을 다시 생성할 때만 `--replace-generated-parts`를 사용합니다. 이 경우에도 먼저 이전 바이트를 `build/reports/model-backups/`에 해시별로 백업합니다. 원본은 삭제하지 않으며 `models/`의 생성 GLB를 직접 편집하지 않습니다. 이후 최적화·검사는 [모델 파이프라인](MODEL_PIPELINE.md)을 따릅니다.

## 검증과 예산

샵은 선택 차량 하나와 뷰포트 하나를 유지하고 변경·회전·부스트 시연이 없으면 3D 갱신을 멈춥니다. 림·윙 메시 캐시는 해당 차량이 소유하므로 샵 종료 시 함께 해제됩니다. 그래픽은 공통 아틀라스 하나를 사용합니다.

[tuning_checks.gd](../tests/tuning_checks.gd)는 네 차량의 실제 메시 분리·삼각형 보존·리버리 셀·휠 공유·색 변경 중 자원 재사용·물리 치수 보존·보호 복원·저장 재로드·손상값·미래 버전 거부를 검사합니다. UI 변경은 실제 렌더러에서 선택·적용·취소·반복 진입을 추가 확인합니다. 전체 절차는 [개발 안내](DEVELOPMENT.md#기본-검사)를 따릅니다.

시안과의 대응: 사선 탭·잘린 모서리 반투명 패널·동적 텍스트 제목·브랜드·노란 사선 적용 버튼을 사용합니다. 옵션의 터치 높이는 54px 이상, 색상은 60px, 글자는 20~36px를 기준으로 하며 제목·브랜드·문구를 이미지에 굽지 않습니다. 실제 차량 모델과 도장·부품이 미리보기에 반영됩니다.

## 번역 가능한 UI

튜닝샵은 Godot의 `auto_translate_mode`를 켜고 Label·Button·확인 창에 영어 원문을 유지합니다. TranslationServer에 등록한 번역은 언어 변경 알림으로 표시하며, 번역 후 문자열로 원문을 덮어쓰지 않습니다. 제목·브랜드도 실제 텍스트입니다. 번역문이 길어지면 정해진 영역 안에서 글자 크기를 조정하고 버튼의 터치 영역은 유지합니다. 번역자가 사용할 원문 목록은 [튜닝 번역 템플릿](../localization/tuning_shop.pot)에 있습니다. 이 변경은 튜닝샵의 번역 기반이며 전체 게임 번역·언어 선택 메뉴를 추가하는 것은 별도 작업입니다. 새 언어는 해당 문자 글꼴과 실제 모바일 화면을 함께 검증합니다. 현재 번들 서체는 라틴 문자 중심이므로 한국어 등은 특히 웹에서 시스템 글꼴에 의존하지 않는 대체 글꼴 번들도 준비해야 합니다.

튜닝샵과 다른 메뉴의 기본 색은 [공용 UI 기준](UI_DESIGN.md)을 따릅니다. `tuning_theme.gd`는 네이티브 컨트롤 스타일을 소유하고 색 상수는 공용 `menu_theme.gd`를 참조합니다.

## 이펙트 슬롯

EFFECTS 탭에서 장착·해제하며 적용·저장·비교·취소는 기존 외형과 같은 초안을 사용합니다. NIMORI는 1개, VELTRIX·IRONVALE는 2개, STRAUD는 3개입니다. 슬롯이 차면 먼저 기존 아이템을 해제합니다. 지원하지 않는 OPEN TOP은 설명과 함께 비활성화합니다. 저장 스키마1은 기존 도장·부품을 유지한 채 빈 효과 목록으로 읽고, 중복·알 수 없는 ID·초과 슬롯·미지원 오픈카를 제거합니다.

| 아이템 | 동작 |
| --- | --- |
| MEGA EXHAUST | 차종 고유 GLB 불꽃·빔의 크기를 확대합니다. 입자 수·주행 출력은 늘리지 않습니다. |
| AIR SPIN 360 | 노면 기준4m 이상의 상승 점프에서 차종에 맞춰 롤 또는 플립을 한 번 수행합니다. 예상 착지 시간 안에서 시각 피벗만 돌리고 실제 방향·속도·충돌은 바꾸지 않습니다. |
| OPEN TOP | STRAUD의 지붕 없는 도장·트림 메시와 좌석·롤오버 바·대시보드·운전대를 장착합니다. 해제 시 원래 메시로 돌아갑니다. |

부스트 시연에서는 대형 배기와 공중 회전을 확인할 수 있습니다. 모델 원본 제작은 [author_effect_models.py](../tools/author_effect_models.py)이며 기존 원본은 해시별로 백업한 뒤 변형을 추가합니다.

속도·니트로의 화면 블러와 방사형 스피드라인은 제거했습니다. 기존 `nitro_blur` 장착 기록은 읽을 때 제외하며, 화면 후처리에는 비 물방울과 번개만 남깁니다.
