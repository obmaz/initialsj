# 해안 메뉴와 네온 레이스 UI

주행 HUD·설정·일시정지·결과는 남색 글래스 카드, 밝은 글자와 시안 네온 강조를 사용합니다. 사용자가 실험 브랜치의 네온 UI를 main에 통합하도록 결정했으며 테마 선택 옵션은 제공하지 않습니다. 홈·트랙 선택·차량 선택·투어 여권·튜닝·로딩의 해안 이미지와 기존 선택 구조는 유지합니다. [menu_theme.gd](../scripts/ui/menu_theme.gd)가 공통 장식과 번역 글자 맞춤을 관리합니다. 날씨·주야간과 UI 색은 독립적이며 세부 책임은 [인수인계](UI_OVERHAUL_HANDOVER.md)에 정리합니다.

설정의 CONTROLS는 조이스틱·페달의 좌우 배치와 세 가지 버튼 크기를 제공하며 실제 배치 미리보기·저장·초기화를 지원합니다. [touch_layout.gd](../scripts/input/touch_layout.gd)의 현재 조합을 캐시하여 그리기·입력·진단이 공유합니다. 설정·일시정지·결과 카드의 짧은 크기 전환은 [modal_motion.gd](../scripts/ui/modal_motion.gd)가 관리하고 풀 Label과 터치도 같은 변환을 사용합니다. 모션 감소는 즉시 전환합니다.

## 시안과 실제 화면

생성형 시안의5개 세로 트랙 카드, 큰 차량 미리보기·우측4개 성능 막대,4개 차량 카드와 하단 조작 행을 구현합니다. 시안의 빈 제목판과 노란 버튼은 잘라 실제 장식으로 사용하고,6개 풍경은 한 아틀라스에서 분리합니다. 원본·추출 좌표·역할은 [이미지 출처](../assets/ui/GENERATED_ART.md)에 기록합니다. 일회성 실제 캡처·비교 로그는 `build/reports/`에 두고 Git에 넣지 않습니다. 장기 디자인 정본은 아래 원화 보존 규칙을 따릅니다.

HUD·카운트다운·설정·결과의 새 [생성형 기준 원화](../art_sources/ui/neon/README.md)는 `art_sources/ui/neon/`에 원본·해시·패널 좌표를 함께 보존합니다. 인수인계에서 누락된 과거 원화를 대체해 사용자 승인 후 만든 새 기준입니다. 이 폴더는 Godot 임포트와 APK/Web 내보내기에서 제외합니다. [neon_chrome.gd](../scripts/ui/neon_chrome.gd)는 컷 모서리·그라디언트·트로피·별·번개를 2D 벡터로 공유하며, 텍스트는 이미지에 굽지 않습니다. 레이스 HUD의 직접 그리기 텍스트도 번역 키를 사용하고 서식이 있는 값은 번역 후 값을 대입합니다. 원화 비교는 콘텐츠 영역의 위치·면적·색·도형·장식과 가독성을 대상으로 하며 3D 차량·배경은 비교 대상에서 제외합니다.

선택 차량은 [garage_previews.gd](../scripts/ui/garage_previews.gd)의 실제3D 차량·튜닝값을 사용합니다. 차량 이미지는 종횡비를 보존해 여백만 잘라 표시합니다. 광원·노출은 밝은 차고에 맞추며 뷰포트는 변경 때만 한 번 렌더링합니다. 사진 속 가상 차량을 실제 선택 차량처럼 표시하지 않습니다.

## 모바일·번역·입력 계약

- 설계 좌표는 1280×720입니다. [hud.gd](../scripts/ui/hud.gd)의 사각형을 그리기와 입력이 함께 사용합니다. 작은 가로 화면 높이 414px 기준 주요 조작 높이는 44px 이상입니다. 트랙은 한 번의 카드 터치로 기존 차량 선택에 연결하고 결과 뒤 복귀 경로도 유지합니다.
- 차량 카드에서 작은 역할 설명을 덜어내고 실제 차량 그림·차명을 표시합니다. 트랙명은 두 줄, 환경 설정과 도색·번호판은 큰 두 줄 버튼으로 표시합니다. 키보드 단축키를 추가하지 않습니다. 게임패드의 메뉴 선택 테두리는 남색·청록 대비를 사용합니다.
- 새 제목·버튼·능력·상태는 실제Label 컨트롤에 표시하는 번역 가능한 텍스트입니다. [menu_text.gd](../scripts/ui/menu_text.gd)의64개 고정 풀을 재사용하며 사용하지 않는 글자는 화면 전환 때 숨깁니다. Label은 터치 입력을 가로채지 않습니다. 생성 이미지에는 문자를 넣지 않습니다. `MenuTheme.layout_text()`가 번역 후 크기를 맞추고 주요 문구는 최소22설계 픽셀에서 말줄임합니다. 원문 키는 변경하지 않습니다. 아주 좁은 영역은 영역을 넘겨 그리지 않습니다. [메뉴 번역 템플릿](../localization/menus.pot)을 언어별 PO로 채워 등록할 수 있습니다. 템플릿만으로 새 언어가 활성화되는 것은 아닙니다.
- 밝은 패널 위 본문·보조 글자는 각각7:1·4.5:1 이상의 대비로 검사합니다. 의미 있는 글자에 어두운 외곽 그림자를 덧씌우지 않습니다.

메뉴 아트는 [hud_menus.gd](../scripts/ui/hud_menus.gd)가 소유합니다. 배경·아틀라스·잘라 쓴 장식은 메뉴에서 읽고 주행 시작 때 참조와 미리 읽기 결과를 해제합니다. 같은 아틀라스의 여섯 영역은 한 이미지 자원을 공유하며 메뉴 렌더에 새3D 패스나 동적 그림자를 추가하지 않습니다.

## 검증

[bright_menu_checks.gd](../tests/bright_menu_checks.gd)는 명암 대비, 아틀라스 공유, 긴 독일어 문구, 모바일 터치·차량 선택·결과 복귀와 메뉴 아트 해제를 검사합니다. 트랙·차량·튜닝·설정·일시정지·결과의 네이티브 캡처를 시안과 비교하고 실제 캡처 크기를 기록합니다. 엔진의 기본16:9 콘텐츠 정책을 유지하므로 창·기기 전체 크기와 캡처된 콘텐츠 크기는 다를 수 있습니다. 폰·폴더블 실기기 플레이는 별도 확인이 필요합니다. 전체 검사는 [개발 안내](DEVELOPMENT.md#기본-검사)를 따릅니다.

## 간결한 주행 HUD

투어와 트랙은 같은 원형 미니맵의 위치·크기·단일 테두리를 공유합니다. [race_hud_layout.gd](../scripts/ui/race_hud_layout.gd)가 상단 24px 바깥 여백·지도 투영·투어 노드 좌표의 정본입니다. 코스명·랩/스테이지 정보는 상단에 한 번 표시하며, 지도에는 경로와 현재 위치만 둡니다. 지도 범위를 벗어난 차량은 안쪽 반지름에 제한합니다. 상단 카드의 StyleBox는 HUD가 한 번 생성해 재사용합니다. 주행 화면 바깥 네온 프레임과 조작 버튼의 겹친 장식은 줄이고, 눌림·니트로 잔량·드리프트 피드백은 유지합니다.

설정의 음악·효과음 카드는 각각 ON/OFF와 0~100 슬라이더를 제공합니다. 기본값은 음악70·효과음50이며 독립적으로 저장합니다. 켜기 영역·슬라이더는 각각80설계 px 높이를 확보합니다. 게임패드는 해당 카드 선택 후 좌우로 음량을5씩 조절합니다. 설정창의 같은 행에 모션 감소/ FPS와 자동 가속/조작 설정을 묶고 웹 전용 전체화면/설치/완료는 하단에 배치합니다.

조향은 [floating_joystick.gd](../scripts/input/floating_joystick.gd)의 연속 가상 조이스틱을 사용합니다. 하단 조향 구역의 첫 접점이 중심이 되고, 놓은 뒤 다른 곳을 누르면 그 지점에 다시 나타납니다. 한 포인터가 소유하며 니트로·페달의 다른 손가락과 섞이지 않습니다. 정지·화면 전환 시 해제합니다. 니트로 준비 완료는 버튼 둘레의 불꽃·링으로 표시하고 모션 감소에서는 정적인 링을 사용합니다.
