# 해안 메뉴와 네온 레이스 UI

주행 HUD·일시정지·결과는 남색 글래스 카드, 밝은 글자와 시안 네온 강조를 사용합니다. 사용자가 실험 브랜치의 네온 UI를 main에 통합하도록 결정했으며 테마 선택 옵션은 제공하지 않습니다. 시작·홈·트랙 선택·차량 선택·설정은 [해안 원화](../art_sources/ui/coastal/README.md)의 실제 픽셀을 통이미지·공통 조각으로 사용합니다. 여권·튜닝의 기존 기능과 선택 구조는 유지합니다. [menu_theme.gd](../scripts/ui/menu_theme.gd)가 공통 장식과 번역 글자 맞춤을 관리합니다. 날씨·주야간과 UI 색은 독립적이며 세부 책임은 [인수인계](UI_OVERHAUL_HANDOVER.md)에 정리합니다.

설정의 CONTROLS는 조이스틱·페달의 좌우 배치와 세 가지 버튼 크기를 제공하며 실제 배치 미리보기·저장·초기화를 지원합니다. [touch_layout.gd](../scripts/input/touch_layout.gd)의 현재 조합을 캐시하여 그리기·입력·진단이 공유합니다. 설정·일시정지·결과 카드의 짧은 크기 전환은 [modal_motion.gd](../scripts/ui/modal_motion.gd)가 관리하고 풀 Label과 터치도 같은 변환을 사용합니다. 모션 감소는 즉시 전환합니다.

## 시안과 실제 화면

[해안 원화](../art_sources/ui/coastal/README.md)의 빈 차량 전시장과 공통 부품을 기준으로 시작·모드 선택·트랙 선택·차량 선택·설정의 투명 RGBA 프레임 통이미지를 사용합니다. 기기 전체에 공유 환경판을 먼저 그리고 중앙 안전 영역에 프레임·실제 텍스트·차량을 합성하며, 중앙 프레임 이미지에 환경을 굽지 않습니다. 생성 원본에서 재단한 프레임을 기존 입력 Rect에 맞춰 재조립하며, 실제 배치의 정본은 화면별 베이크 이미지와 [재단·배치 자료](../art_sources/ui/coastal/layout.json)입니다. 마스터 원본의 전체 구도를 실제 메뉴 좌표라고 가정하지 않습니다. 코스 풍경 여섯 영역은 기존 공유 아틀라스를 유지합니다. 출처·추출 좌표는 [이미지 출처](../assets/ui/GENERATED_ART.md)에 연결하고 실제 캡처·비교 로그는 `build/reports/pre-race-art/`에 둡니다.

기존 주행 HUD·카운트다운·결과 등 네온 화면의 참고 원화는 [neon 원본](../art_sources/ui/neon/README.md)에 보존합니다. 설정의 현재 기준은 밝은 해안 통이미지이며 메뉴·일시정지에서 공용으로 사용합니다. 주행 HUD·결과·일시정지 자체는 이번 원화 통합에서 바꾸지 않습니다. 생성 원본은 Godot 임포트·내보내기에서 제외하고, 제목·브랜드·버튼·값은 번역 가능한 실제 텍스트로 그립니다. 원화 비교는 정적인 아트의 위치·비율·색·장식과 가독성을 대상으로 하며, 실제 차량·동적 값은 별도 레이어로 확인합니다.

선택 차량은 [garage_previews.gd](../scripts/ui/garage_previews.gd)의 실제3D 차량·튜닝값을 사용합니다. 차량 이미지는 종횡비를 보존해 여백만 잘라 표시합니다. 광원·노출은 밝은 차고에 맞추며 뷰포트는 변경 때만 한 번 렌더링합니다. 사진 속 가상 차량을 실제 선택 차량처럼 표시하지 않습니다.

## 모바일·번역·입력 계약

- 설계 좌표는 1280×720입니다. [hud.gd](../scripts/ui/hud.gd)의 사각형을 그리기와 입력이 함께 사용합니다. 작은 가로 화면 높이 414px 기준 주요 조작 높이는 44px 이상입니다. 트랙은 한 번의 카드 터치로 기존 차량 선택에 연결하고 결과 뒤 복귀 경로도 유지합니다.
- 차량 카드에서 작은 역할 설명을 덜어내고 실제 차량 그림·차명을 표시합니다. 트랙명은 두 줄, 환경 설정과 도색·번호판은 큰 두 줄 버튼으로 표시합니다. 키보드 단축키를 추가하지 않습니다. 게임패드의 메뉴 선택 테두리는 남색·청록 대비를 사용합니다.
- 제목·버튼·능력·상태는 번역 가능한 런타임 텍스트입니다. 메뉴의 글자는 실제 Label 컨트롤에 표시합니다. [menu_text.gd](../scripts/ui/menu_text.gd)의64개 고정 풀을 재사용하며 사용하지 않는 글자는 화면 전환 때 숨깁니다. Label은 터치 입력을 가로채지 않습니다. 생성 이미지에는 문자를 넣지 않습니다. `MenuTheme.layout_text()`가 번역 후 크기를 맞추고 주요 문구는 최소22설계 픽셀에서 말줄임합니다. 원문 키는 변경하지 않습니다. 아주 좁은 영역은 영역을 넘겨 그리지 않습니다. [메뉴 번역 템플릿](../localization/menus.pot)을 언어별 PO로 채워 등록할 수 있습니다. 템플릿만으로 새 언어가 활성화되는 것은 아닙니다.
- 밝은 패널 위 본문·보조 글자는 각각7:1·4.5:1 이상의 대비로 검사합니다. 의미 있는 글자에 어두운 외곽 그림자를 덧씌우지 않습니다.

메뉴 아트는 [hud_menus.gd](../scripts/ui/hud_menus.gd)가 소유합니다. 대형 메뉴 아트는 현재 투명 프레임 통이미지 한 장과 공유 환경판 한 장을 보유하고 이전 통이미지는 직전 그리기 명령 교체 뒤 놓습니다. 같은 원화에서 재단한 공통 부품과 여섯 코스 풍경 아틀라스는 공유합니다. 주행 시작 때 통이미지·환경판의 메뉴 참조와 미리 읽기 결과를 모두 비우며, 메뉴 장식을 위해 새3D 패스나 동적 그림자를 추가하지 않습니다.

## 검증

[pre_race_art_checks.gd](../tests/pre_race_art_checks.gd)와 [bright_menu_checks.gd](../tests/bright_menu_checks.gd)는 명암 대비, 공통 아트, 긴 문구, 모바일 터치·차량 선택·복귀와 메뉴 아트 수명을 검사합니다. 독립 검증은 작업 전체 최대5회이며 실제 판정·회차는 `build/reports/pre-race-art/`에 기록합니다. 트랙·차량·튜닝·설정·일시정지·결과의 네이티브 캡처를 시안과 비교하고 실제 캡처 크기를 기록합니다. 부팅·시작 전 메뉴는 Window 콘텐츠 정책에 `EXPAND`를 사용하고 기기 전체 환경판을 그립니다. 원화 프레임·텍스트·입력은 안전 영역의16:9 콘텐츠 좌표를 공유하며, 주행 진입 때 기존 `KEEP` 정책을 복원합니다. 창·기기 전체 크기와 중앙 메뉴 콘텐츠 크기는 다를 수 있으므로 전체 바탕과 콘텐츠를 각각 확인합니다. 폰·폴더블 실기기 플레이는 별도 확인이 필요합니다. 전체 검사는 [개발 안내](DEVELOPMENT.md#기본-검사)를 따릅니다.

## 간결한 주행 HUD

투어와 트랙은 같은 미니맵 위치·크기를 공유하고 배경·외곽 테두리는 표시하지 않습니다. [race_hud_layout.gd](../scripts/ui/race_hud_layout.gd)가 상단 16px 바깥 여백·지도 투영·투어 노드 좌표의 정본입니다. 상단 HUD는 중앙16:9 콘텐츠 대신 OS 안전 영역 양끝에 맞추며, 일시정지 터치 영역도 그 위치를 따릅니다. 미니맵은 실제 지도선·노드의 위·오른쪽을 맞춰, 투어와 납작한 트랙의 보이지 않는 프레임 안쪽 여백이 늘어나지 않게 합니다. 코스명·랩/스테이지 정보는 상단에 한 번 표시하며, 지도에는 경로와 현재 위치만 둡니다. 지도 범위를 벗어난 차량은 지도 영역 안으로 제한합니다. 화면·안전 영역이 바뀌면 도로선 캐시도 다시 투영합니다. 상단 카드의 StyleBox는 HUD가 한 번 생성해 재사용합니다. 주행 화면 바깥 네온 프레임과 조작 버튼의 겹친 장식은 줄이고, 눌림·니트로 잔량·드리프트 피드백은 유지합니다.

설정의 음악·효과음 카드는 각각 ON/OFF와 0~100 슬라이더를 제공합니다. 기본값은 음악70·효과음50이며 독립적으로 저장합니다. 켜기 영역·슬라이더는 각각80설계 px 높이를 확보합니다. 게임패드는 해당 카드 선택 후 좌우로 음량을5씩 조절합니다. 설정창의 같은 행에 모션 감소/ FPS와 자동 가속/조작 설정을 묶고 웹 전용 전체화면/설치/완료는 하단에 배치합니다.

조향은 [floating_joystick.gd](../scripts/input/floating_joystick.gd)의 연속 가상 조이스틱을 사용합니다. 하단 조향 구역의 첫 접점이 중심이 되고, 놓은 뒤 다른 곳을 누르면 그 지점에 다시 나타납니다. 한 포인터가 소유하며 니트로·페달의 다른 손가락과 섞이지 않습니다. 정지·화면 전환 시 해제합니다. 니트로 준비 완료는 버튼 둘레의 불꽃·링으로 표시하고 모션 감소에서는 정적인 링을 사용합니다.

주행 미니맵에는 원형 배경·테두리를 그리지 않습니다. 도로선·경로·마커에 어두운 외곽선을 두어 밝은 하늘과 어두운 노면에서 대비를 유지합니다. 속도계는 좌측의 작은 숫자·기어·RPM만 표시합니다. 조이스틱은 반경90px, 이동72px이며 기본 중심과 페달 중심은 y620입니다.

기본 크기의 조이스틱과 우측 페달의 바깥 여백은90px로 맞춥니다. 좌우 반전에도 같은 여백을 적용하며 상단 HUD 배경은60% 불투명도의 약한 남색을 사용합니다.

## 생성형 원화 기반 시작 전 화면

실행 기준은 [작업 계획](PRE_RACE_ART_PLAN.md)과 [디자인 계약](PRE_RACE_ART_DIRECTION.md)입니다.
[재단 도구](../tools/bake_pre_race_art.py)는 글자 없는 원화에서 프레임을 잘라 실제 HUD 입력 Rect로 5종 통이미지를 만듭니다.
공유 환경판을 기기 전체에 cover로 채우고, 환경을 포함하지 않는 투명 프레임 통이미지를 중앙에 그대로 그린 뒤 실제 문자열·차량·값·선택을 얹습니다. 중앙·바깥 환경을 별도 배율로 중복해서 굽지 않습니다. 원화와 입력은 같은1280×720 변환을 사용합니다.
원화를 다시 벡터로 해석하지 않으며 공통 부품도 같은 재단 이미지의9분할을 사용합니다. 원본 재단 여백은20px로 고정하고 목적지 여백만 작은 Rect에 맞춰 줄입니다. 배포용 `backdrop.png`가 기기 전체를 cover로 채우고 중앙의 프레임은 비율을 유지합니다. 차량 선택의 환경판만 그리는 동안 수평 변환으로 반전하며 프레임·입력은 반전하지 않습니다. 조작 설정도 같은 밝은 환경과 프레임을 공유합니다.
현재 투명 프레임 통이미지 한 장과 공유 환경판 한 장을 보유하고 이전 통이미지는 직전 렌더 명령이 교체된 뒤 놓습니다. 주행 진입 때 두 이미지의 메뉴 참조와 미리 읽기를 모두 비웁니다.
엔진 최초 스플래시는 공용 환경판만 사용합니다. 실제 부트·긴 로딩은 환경판·`start.png` 투명 프레임·실제 제품명·진행 상태를 합성하며 필요한 동안만 읽습니다. 짧은 전환은 진행 표시를 사용합니다.
터치한 실제 사각형은 짧은 반사·안쪽 강조·2px 눌림을 공유하고, 동작 감소에서는 위치를 움직이지 않습니다.
선택 카드는 청록색 강조선을 사용하고 효과음은 기존 효과음 음량 버스를 따릅니다.
생성 원본·재단 좌표·해시는 [원화 정본](../art_sources/ui/coastal/layout.json)에 보존합니다.
