# 게임 규칙과 화면

## 모드와 코스

**TOUR**는 제한 시간 70초로 시작해 5구간을 완주하는 오픈 로드 모드입니다. 15개 지역 노드에서 16개의 좌우 경로가 만들어집니다. 오른쪽 선택을 누적할수록 거리가 길어지고 도로 폭, 코너, 교통량과 시간 압박이 어려워집니다. 구간 길이와 테마·보상은 [route_library.gd](../scripts/route_library.gd)가 정의합니다.

체크포인트는 실제 갈림길보다 720m 앞에 있습니다. 통과하면 완료한 경로에 따라 54~60초를 한 번 지급하고, 직선 안내 구간에 큰 좌우 선택 카드를 표시합니다. 가장 빠른 부스트와 게임 템포에서도 분기 전 약 5.26초 이상 안내합니다. 터치 선택은 분기 직전 차선 안내를 돕고, 직접 조향하면 수동 조작이 우선합니다. 시간 초과 또는 마지막 구간 도착으로 종료합니다.

**TRACK**은 투어 제한 시간 없이 플레이어를 포함한 8대가 3바퀴를 달립니다. 상대 차량은 고정 참가자이며 투어처럼 재배치하지 않습니다.

| 코스 | 구성 |
| --- | --- |
| FUJI LAKESIDE | 약 5.72km. 약 60.8m 고저차·최대 약 12도 뱅킹, 호수·산악 코너·지하차도·고가 교차 구간 |
| SUNCOAST SPEEDWAY | 약 4.57km. 넓은 트라이오벌, 최대 약 26도 뱅킹, 피트·관제탑·관중석·안전 펜스 |

트랙 1은 실제 3D 노면·장벽 충돌체와 차량 몸체로 주행합니다. 조향은 차체 방향을 바꾸며, 곡선에서 계산하는 거리·차선 값은 순위·미니맵·경기 진행용 정보입니다. 고가 구간은 평면상 같은 위치를 높이 약 35m 차이로 지나갑니다. 12개 게이트를 순서대로 통과해야 랩으로 인정하고 3랩에서 종료합니다. 정지 후 BRAKE/S를 약 0.45초 계속 누르면 후진할 수 있습니다.

투어와 SUNCOAST는 기존 거리·차선 기반 아케이드 조작을 사용합니다. SUNCOAST의 뱅킹은 실제 노면 높이·차량 기울기와 접지력 보조에 반영됩니다. 제품 내 이름과 간판은 독자적인 이름을 사용합니다.

## 차량과 니트로

차량 능력치는 **최고속도·가속도·부스트·핸들링** 네 가지입니다. [vehicle_catalog.gd](../scripts/vehicle_catalog.gd)의 실제 주행 수치로 비교하며, [vehicle_factory.gd](../scripts/vehicle_factory.gd)가 쇼룸과 주행의 동일 모델·재질을 만듭니다.

| 차량 | 성격 | 니트로 자원 |
| --- | --- | --- |
| NIMORI H | 조향과 드리프트 접지력이 좋은 흰 해치백 | 누르는 동안 게이지 소비, 일반 주행·드리프트 등으로 회복 |
| VELTRIX S | 높은 최고속도와 강한 부스트, 비교적 느린 출발 | 한 번 눌러 2.4초 사용, 최대 3회 |
| IRONVALE V8 | 강한 가속과 무거운 조향 | 게이지 + 별도 셀 2개, 셀은 1.6초 오버드라이브 |

니트로는 충분한 속도에서 가속 중 사용할 수 있습니다. 횟수형과 셀은 입력의 새 누름을 감지하므로 계속 눌러도 다음 횟수를 자동 소비하지 않습니다. 브레이크·드리프트·충돌은 진행 중인 부스트를 취소하며 사용한 횟수를 돌려주지 않습니다. 체크포인트와 서킷 랩 통과에서 횟수·셀을 한 개씩 회복합니다. 게이지는 드리프트·근접 추월·체크포인트와 일반 주행으로 회복됩니다.

## 주행과 노면

드리프트는 약 90km/h 이상에서 조향과 함께 DRIFT/Space를 한 번 누르거나, 브레이크를 짧게 누른 뒤 조향·가속해 시작합니다. 버튼을 먼저 누르면 약 0.55초 동안 조향 입력을 기다립니다. 다시 누르면 해제되며 재사용 대기시간은 없습니다. 조향으로 방향을 보정할 수 있고, 충분히 감속하거나 접지력이 안정된 직선에서 조향을 풀면 종료됩니다. 앞차 뒤를 따라가면 슬립스트림을 얻습니다.

- **부스터 패드**: 니트로 소비 없이 잠시 가속하며 브레이크나 충돌로 취소됩니다. 투어 첫 구간에는 양쪽에 엇갈린 패드가 있습니다.
- **후지산 트랙1**: 부스터 패드 5개와 점프대 3개가 있습니다. 출발 직선·지하차도 접근·고가 구간에 부스트 후 점프로 이어지는 선택 경로를 배치하며, 옆 차선으로 피할 수도 있습니다.
- **물웅덩이**: 접지력과 횡방향 응답이 잠시 낮아집니다. 진입할 때만 물보라가 나고 이후 접지력을 회복합니다.
- **점프대**: 투어 일부 구간과 두 서킷에 있습니다. 빠르게 진입하면 중력 궤적을 따라 점프하고, 느린 차량은 작은 낙하로 이어집니다. 공중 차량은 지나친 지상 패드·웅덩이를 밟지 않습니다.
- **흙 갓길**: 일부 가드레일은 노면 바깥으로 물러나 있습니다. 갓길은 저항·접지력 감소로 느려지고 실제 가드레일에 닿을 때 충돌합니다.

트랙 1의 접촉은 실제 차체와 노면·장벽 충돌체로 처리합니다. 투어·SUNCOAST 접촉은 도로 위치와 차체 방향의 겹침, 실제 높이를 사용합니다. CPU도 노면 효과와 점프를 적용하고 앞차 간격·차선 이동·코너 감속을 판단합니다. 충돌 강도와 방향에 맞는 짧은 반동·불꽃·작은 파편을 사용하며 정지·미세 접촉은 과한 피드백을 억제합니다. 움직임 줄이기에서는 충돌 카메라·차체 진동과 파편을 생략하고 불꽃도 줄입니다. 평상시 주행에 상시 파티클을 뿌리지 않습니다.

## 화면과 모바일 동작

메인에서 TOUR 또는 TRACK을 고르고, TRACK은 코스 선택을 거쳐 차량을 고릅니다. 준비된 코스는 출발 때 재사용하며 화면 사이에는 짧은 페이드·슬라이드를 사용합니다. 로딩·홈·차고·코스 카드는 현재 차량·코스 콘셉트에 맞춘 생성형 이미지이고, 차고에 표시하는 차량 자체는 실제 게임 모델입니다.

| 현재 화면 | 안드로이드/브라우저 뒤로가기 |
| --- | --- |
| 주행·출발 대기 | 일시정지 |
| 일시정지 | 중단한 상태로 재개 |
| TRACK 차량 선택 | 코스 선택 |
| TOUR 차량 선택·코스 선택 | 메인 메뉴 |
| 설정 | 설정을 열었던 화면 |
| 결과 | 차량 선택 |
| 화면 전환 중 | 중복 이동 없이 입력 소비 |
| 메인 메뉴 | 정상 사이트 이탈 |

설치 안내가 열려 있으면 뒤로가기로 안내부터 닫습니다. 브라우저 앞으로 가기로 복원해도 다시 사이트 밖으로 밀어내지 않습니다. 주행·출발 대기 중 세로 전환 또는 포커스 이탈 시 멈추며, 가로 화면으로 돌아온 뒤 직접 재개합니다. 화면의 가로 전환 요청은 브라우저 지원에 따라 실패할 수 있어 수동 회전 안내를 함께 제공합니다.

소리·움직임·그래픽 설정은 `user://settings.cfg`, 차량·모드·코스별 최고 기록은 `user://records.cfg`에 저장합니다. AUTO 그래픽은 웹에서 중간 품질로 시작해 연속으로 느린 주행 프레임을 감지하면 3D 해상도·그림자·블러를 줄입니다. UI 해상도는 유지합니다.

오픈 로드 구성과 브레이크·조향·가속 드리프트의 참고 자료는 [OutRun 2006 매뉴얼](https://oldgamesdownload.com/manual/outrun-2006-coast-2-coast-windows-manual-english/)입니다. 코스·차량·아트·코드는 이 프로젝트의 독자적인 구현입니다.
