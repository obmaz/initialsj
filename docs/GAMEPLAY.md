# 게임 규칙과 조작

## 모드와 코스

| 모드 | 경기 | 주요 요소 |
| --- | --- | --- |
| TOUR | CPU 없는5구간 타임어택 | 15개 지역 테마·16개 경로, 체크포인트와 양쪽 분기 |
| TRACK01 / FUJI LAKESIDE | 8대·3랩, 약5.72km | 호수·마을·뱅킹·고가 교차 |
| TRACK02 / SUNCOAST SPEEDWAY | 16대·3랩, 약4.57km | 두 줄로 분산한 롤링 스타트와 기록 전광판 |
| TRACK03 / MIDNIGHT HARBOR | 8대·3랩, 약2.75km | 야간 항만·헤어핀·연속 S자·드리프트 안내 |
| TRACK04 / AZURE RIVIERA | 8대·3랩, 약3.64km | 해안 마을·협곡·폭 축소·붕괴 아치 |
| TRACK05 / SCARLET GORGE | 8대·3랩, 약3.54km | 노을·현수교·상판 붕괴·점프·낙석 |

모든 모드는 실제3D 차체가 노면과 장벽 위를 달립니다. 투어의 체크포인트는 시간과 니트로를 회복하고 다음 지역의 왼쪽·오른쪽 경로를 고르게 합니다. 수동 조향이 우선하며 분기 선택은 조향 보조로 작동합니다. 제한시간 안에 다섯 구간을 지나면 완주입니다.

트랙은 순서 있는 게이트와 출발선을 지나야 랩으로 인정합니다. 트랙2는 카운트다운 동안35m/s로 굴러오고 GO부터 경기 시간을 잽니다. 출발선 위 대형 전광판에는 실제 상위3개 완주 기록과 현재 차량의 개인 베스트를 표시하며, 기록이 없으면 `--:--.---`를 표시합니다.

## 차량과 니트로

| 차량 | 특성 | 니트로 |
| --- | --- | --- |
| NIMORI H | 가벼운 조향·코너 탈출·낮은 최고속도 | 게이지, 누르는 동안 사용 |
| VELTRIX S | 높은 최고속도·강한 부스트·느린 출발 | 새로 누를 때마다 한 샷 |
| IRONVALE V8 | 강한 출발·묵직한 조향 | 게이지와 별도 오버드라이브 셀 |
| STRAUD 6R | 균형 잡힌 속도·강한 제동 | 빠르게 회복하는 짧은 게이지 |

능력 표시와 실제 수치는 `vehicle_catalog.gd`를 함께 사용합니다. 횟수형·셀은 버튼을 계속 누르고 있어도 다음 횟수를 자동 소비하지 않습니다. 브레이크·드리프트·충돌은 진행 중인 니트로를 취소합니다. 게이지는 일반 주행·드리프트·근접 추월·체크포인트로 회복하고, 체크포인트·랩은 횟수와 셀도 회복합니다. 각 차량은 독립된 엔진·부스터·점화·드리프트 음원을 사용합니다.

## 주행과 노면

- **드리프트**: 약90km/h 이상에서 조향과 함께 진입합니다. TOUR와 TRACK04·05는 실제 접지 슬립으로 하트·점수·최대5배 콤보를 쌓으며 짧은 S자 연결을 유지합니다. 충돌·노면 이탈은 연결을 끊습니다.
- **부스터 패드·차로**: 노면의 화살표·색 띠로 표시합니다. 실제 접지한 바퀴가 통과해야 적용됩니다.
- **물·진흙**: 접지력·속도에 영향을 주며 공중 통과는 노면 효과를 받지 않습니다.
- **점프·고가 통로**: 실제 경사와 차체 속도로 비행하고 착지합니다. 고가 통로에는 진입 램프가 있고 옆으로 벗어나면 아래 도로로 떨어집니다.
- **트럭·장벽**: 실제 차체와 충돌합니다. 정지 후 BRAKE/S를 잠시 유지하면 후진합니다.
- **가드레일**: 가벼운 접촉은 옆으로 반동을 주며 충격이 크면 날아가고 구릅니다. 복구 안내가 나오면 남아 있는 안전한 노면으로 차량을 되돌릴 수 있습니다.

차량·노면·벽·카메라 조정의 정본은 `world_car.gd`, `drive_tuning.gd`, `road_surface_state.gd`입니다.

## 코스별 환경과 위험

TRACK03은 야간·터널에서 전조등을 켭니다. 상대 차량은 발광 렌즈로 표시하고, 실제 도로를 비추는 전조등은 플레이어가 사용합니다. 급커브 앞 표지는 `LEFT/RIGHT CURVE · DRIFT`로 방향과 의미를 안내합니다.

TRACK04는 세 마을에 시골집·가게10종을 모으고 터널·다리·협곡 접근부를 비웁니다. 두 협곡의 폭이 완만하게 좁아지며 선택형 점프2곳·패드5곳·부스트 차로2곳이 있습니다. 아치2개는 첫 랩에 유지되고 다음 랩 접근 중 눈앞에서 무너집니다. 중앙에는 잔해가 남고 양쪽 통과로를 이용할 수 있습니다.

TRACK05는108m 구간의 오른쪽 상판이 균열 뒤 순차 붕괴하고 실제 바닥도 사라집니다. 직전 점프대로 건너거나 왼쪽 통과로를 이용합니다. 파손·노출 구조와 안내는 다음 랩에도 남습니다. 낙석은 랩마다 도로 안에 한 번9개, 도로 밖에 다섯 번씩14개가 떨어집니다. 도로 안 낙석은 이전 구간과 충분한 거리를 두고 중앙 통과 폭을 남깁니다. 이전 랩의 잔해는 유지하고 재시작 때 초기화합니다.

광고는 SJRPG·킹왕짱 각3종, 상품10종별3종과 가상 브랜드를 포함한48종입니다. 경기 중 위치별 광고는 유지하고 재시작 때 다시 섞습니다.

## 키보드·터치

| 입력 | 동작 |
| --- | --- |
| W/↑, S/↓ | 가속·제동, 정지 후 제동 유지 시 후진 |
| A/D, ←/→ | 조향 |
| Space | 드리프트 진입·해제 |
| Shift, E | 니트로, 머슬카 셀 |
| P/Esc | 일시정지·재개 |
| Enter | 선택 차량으로 출발·결과에서 차량 선택 |
| R, G | 재시작, 일시정지 화면에서 메인 메뉴 |

터치는 화면의 조향·GAS·BRAKE·DRIFT·NITRO·CELL·복구 버튼을 사용합니다. 시간 패널은 주행 중 일시정지 버튼입니다.

## 게임패드

| 입력(Xbox 이름 기준) | 동작 |

PlayStation 패드는 해당 버튼 이름으로 표시합니다. 키보드·마우스·터치를 사용하면 화면 안내도 해당 입력으로 바뀝니다. 패드 연결 해제는 경기를 일시정지하고 입력을 해제합니다.

## 화면과 설정

로딩·메인·설정에 앱 버전을 표시합니다. 웹은 프로젝트 버전·소스 커밋, Android는 APK 버전명·번호를 사용합니다. 설정에는 소리·움직임 줄이기·AUTO/HIGH/FAST 그래픽·FPS·전체화면·설치 안내가 있습니다.

세로 화면·포커스 이탈은 주행을 멈춥니다. Android·브라우저 뒤로가기는 주행 중 일시정지, 정지 중 재개, 선택·설정에서 이전 화면으로 연결됩니다. 메인 메뉴에서는 사이트를 나갈 수 있습니다. 브라우저 전체화면은 마우스·터치로 요청합니다.

## 투어 풍경

놀이공원에는 관람차·고저차 롤러코스터·흔들리는 바이킹·회전목마·역 플랫폼·매점·벤치·광장이 있습니다. 온대 숲은 SJRPG의 입체 활엽수2종·침엽수3종·관목2종을 사용하며 열대 야자수와 대나무는 해당 지역 수종을 유지합니다. 마지막 협곡·항만·대나무숲·설산·화산에는 각각 생성형 파노라마가 있으며, 골 진입 방향에 중심을 맞추고 실제 시선 방향으로 다른 범위를 표시합니다. 바다는 생성형 잔물결·포말 표면을 두 방향으로 이동하며 파도 법선·반사와 혼합합니다.

지역별 컨셉·날씨·시간대·난이도 정본은 `scripts/tour_region_metadata.gd`입니다. 비 후보는 오브젝트가 드문 유적·협곡이며, 여행 시드와 직전 구간의 실제 날씨로 확정합니다. 모든16개 분기 경로에서 비가 연속으로 연결되지 않습니다. 피라미드는 모래 날림 없이 고대 유적 풍경, 설산은 눈 날림을 사용하며 터널과 메뉴에서는 입자 방출을 멈춥니다. 모래·눈·잔디는 각각 생성형 재질4종을 혼합하며 도로 밖에는 사구·눈 언덕·완만한 잔디 굴곡이 있습니다. 공원에 전용 외벽을 사용하는 가게4종과 추가 광고판10개를 배치합니다. 난이도 메타정보는 기획값으로 차량 능력치를 자동 변경하지 않습니다.

투어2구간의 왼쪽 경로는 JUNGLE CANOPY 정글입니다. 녹색 구릉·입체 활엽수·야자수·대나무를 배치하고 피라미드는 모래 입자를 방출하지 않습니다. 구름 파노라마는 투어 전 구간에서 사용하며, 마지막5지역은 진입 직후부터 거리 제한 없는 하늘 배경과 수평선 보정을 적용합니다.

## 벽 충돌과 투어 장애물

벽 충돌은 감속 후 짧게 반동하며, 일반 충돌에서는 멈춤 연출을 적용하지 않습니다. 200km/h 초과이면서 벽 접선 기준 진입각30도 초과일 때만 비행하며, 상승 속도는5~9.5m/s로 제한합니다. 일반 승용차도 투어의 한쪽 차로에 배치하며 차량 접촉은 벽 비행으로 처리하지 않습니다. 투어에는 터널·다리·체크포인트를 피해500m 폭의25~33m 추가 능선을 배치합니다.

트랙2는6초·약210m의 롤링 진입 후 출발하며,16대 대열은 약344m에 걸쳐 두 줄로 분산됩니다. 다른 코스는 기존 출발 방식을 유지합니다. VELTRIX의 가속 평점은4.0(14.4m/s²), IRONVALE은 최고속·가속·부스터·핸들링 평점이 각각1 증가하며 실제 최고속83.2m/s·가속23.2m/s²·부스터 가속36.1m/s²·핸들링5를 사용합니다.

건물 팩의 가로·높이·깊이는 기존 대비2배이며 커진 부지 반경으로 도로·위험 지형과의 이격을 계산합니다. 정글은 도로 양쪽에12m 간격의 세 겹 숲을 두고 분기 입구·터널·다리 여유를 유지합니다. 트랙3·4·5 선택 카드는1·2와 같은 풍경 일러스트 계열의 생성형 아틀라스를 공유합니다.
