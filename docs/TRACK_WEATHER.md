# 공용 트랙 환경 설정

트랙 선택·공용 설정의 **WEATHER**(CLEAR·RAIN), **TIME OF DAY**(DAY·DUSK·NIGHT)는 트랙1~5에 모두 적용합니다. `user://settings.cfg`의 `track_environment`에 저장하며 진입·재시작 때 활성값을 고정합니다. 경기 중 변경은 다음 경기에 적용합니다. 투어는 각 지역의 날씨·시간 메타정보를 유지합니다. UI 문자는 [번역 템플릿](../localization/track_environment.pot)의 실제 텍스트입니다.

## 하늘과 광원

[track_environment.gd](../scripts/environment/track_environment.gd)는30조합의 선택·활성값·광원 프리셋을 관리하고 [race_lighting.gd](../scripts/rendering/race_lighting.gd)가 적용합니다. 투어로 전환할 때 주변광·노출·안개를 복구합니다. 터널 주변광 보정도 유지합니다.

후지는 기존3패널360도 원경을, 다른 트랙은 위경도 파노라마를 공유합니다. [track_weather.gdshaderinc](../shaders/track_weather.gdshaderinc)는 시간대별 하늘·강수 구름·별과 생성형 달 표면을 합성합니다.5트랙의 달 위상·회전은 다르며 트랙5는 가로등 없는 별 많은 하늘과 희미한 은하 띠를 사용합니다. 항만은 달이 이미지에 구워진 옛 야경 대신 중립 낮 파노라마를 사용하고 원본 수평선 높이를 보정합니다. 하늘은 정적 셰이더로 방사휘도를 매 프레임 갱신하지 않습니다.

[course_lighting.gd](../scripts/environment/course_lighting.gd)는 코스별 GLB 가로등·광고 투광등을 연결합니다. 가로등 수는 후지20·스피드웨이87·항만17·리비에라21·협곡0개입니다. 후지는 어둡고 드문 조명, 스피드웨이는 촘촘한 경기장 조명을 사용합니다. 등기구와 광고 인쇄면은 밤·저녁에 발광하며 낮에는 꺼집니다. 광고 재배열 후 다시 적용해 새 인쇄면도 점등합니다. 투어 야간 광고도 같은 물리 등기구·발광 재질을 사용합니다.

실제 SpotLight는 코스마다4개를 재사용하고 화질별4·3·2개만 켭니다. 모바일의 비 오는 밤은 최대2개이며 가로등의 실제 광원 반경을62m에서46m로 제한합니다. 등기구·광고의 발광과 노면 조회 조명은 유지합니다. 그림자를 만들지 않으며0.15초마다 가까운 등기구에 배치합니다. 가로등이 있는 코스는 광고광 최대1개로 제한해 노면용 조명을 확보합니다. 도로의 약한 광택 웅덩이는 실제 등 위치를 기록한 작은 조회 텍스처를 사용합니다. 터널에는 가상의 조명을 추가하지 않습니다. 원본·생성 규약은 [모델 파이프라인](MODEL_PIPELINE.md)을 따릅니다.

## 비·노면·차량 접지

[tour_weather.gd](../scripts/environment/tour_weather.gd)의 단일 입자 시스템을 공유하며 투어와 트랙 모두 화질별240·160·90개로 제한하며 모바일 야간 비는 최대160개입니다. 터널 판정은 이미 계산한 주행 거리를 공유하며 매 렌더 프레임에 도로 전체를 검색하지 않습니다. 지하차도·메뉴·일시정지·동작 줄이기에서는 새 비를 방출하지 않습니다. 저녁·밤·비에서는 플레이어 전조등을 켭니다.

[asphalt.gdshader](../shaders/asphalt.gdshader)는 물 고임에 따른 거칠기·색·클리어코트와 현재 하늘의 제한된 반사를 사용합니다. 화면 공간 반사나 추가 렌더 타깃을 만들지 않습니다. 원경 텍스처를 도로도 공유하며 투어의 미연결 반사 샘플러는 읽지 않습니다. 노면 표시도 젖음 값을 받습니다. 플레이어 차체·바퀴 주변의 접지 음영은 실제 바퀴 위치와 노면 법선을 사용하고 다른 고도의 도로에는 나타나지 않습니다. 차체의 실제 높이·충돌을 강제로 내리지 않습니다.

[rain_lens.gd](../scripts/effects/rain_lens.gd)는 비에서 니트로 사용 시 화면 가장자리에 물방울 굴절·비대칭 하이라이트를 더하고 사용 종료 후 약2초 동안 소멸시킵니다. 중앙 시야와 HUD는 보호합니다. 기존 [speed_blur.gdshader](../shaders/speed_blur.gdshader)의 한 화면 패스 안에서 처리하며 모바일은 두 번째 물방울 층을 생략합니다. 일시정지 시 시간이 멈추고 메뉴·맑은 날·동작 줄이기에서는 해제합니다.

모바일 야간 비는 고화질을 유지하면서3D 해상도 상한을1600×900(중간1440×810·성능1280×720)으로 제한합니다. 비구름 아래의 약한 달빛은 그림자 맵을 만들지 않고 차체 접촉 음영·전조등·광고 투광등을 유지합니다. UI 해상도와 조작 영역은 변하지 않으며 다른 환경으로 바뀌면 원래 예산을 복구합니다.

비는 시각 효과이며 마찰·제동·차량 성능을 바꾸지 않습니다. 트랙 기록·곡률 표를 유지합니다. 폴더블 고화질의 실제 GPU 비용·FPS는 실기기 확인이 필요합니다.

## 검증

[track_environment_checks.gd](../tests/track_environment_checks.gd)는30조합, 저장 복구,5달 위상, 코스별 광량·등 밀도·실제 광원 상한, 전조등·비·터널·물방울 생명주기와 재질 격리를 검사합니다. 렌더 변경은 실제 네이티브 화면에서 셰이더 오류·시인성도 확인합니다. 공통 검사는 [개발 안내](DEVELOPMENT.md#기본-검사)를 따릅니다.
