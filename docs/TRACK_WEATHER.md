# 공용 트랙 환경 설정

트랙 선택 화면과 공용 설정 화면에서 **WEATHER**(CLEAR·RAIN)와 **TIME OF DAY**(DAY·DUSK·NIGHT)를 선택합니다. 값은 모든 트랙이 공유하는 `user://settings.cfg`의 `track_environment` 섹션에 저장합니다. 현재 실제 적용 대상은 **트랙1 FUJI LAKESIDE**이며 트랙2~5와 투어의 기존 환경은 유지합니다. 선택값은 코스 진입·경기 재시작 시 활성값으로 고정합니다. 진행 중인 경기나 일시정지 설정 변경은 다음 경기부터 반영하며 화면에 `TRACK 1 · NEXT RACE`를 표시합니다.

## 소유권과 적용

- [track_environment.gd](../scripts/environment/track_environment.gd)는 공용 선택·검증·활성값·시간대 광원 프리셋을 소유합니다. 잘못된 저장값은 맑은 낮으로 복구합니다. [race.gd](../scripts/race/race.gd)의 기존 설정 저장 경로를 함께 사용합니다.
- [race_lighting.gd](../scripts/rendering/race_lighting.gd)는 트랙1에서 활성 프리셋을 적용합니다. 다른 코스는 기존 고정 광원을 유지합니다. 비는 시간대의 기본 광량에 보정하므로 비 오는 밤이 맑은 밤보다 밝아지지 않습니다. 지하차도 안의 주변광 보정은 유지합니다.
- [fuji_sky.gdshader](../shaders/fuji_sky.gdshader)는 기존360도3패널 원경을 공유합니다. 맑은 낮은 기존 이미지를 유지하고 저녁은 따뜻한 하늘과 낮은 태양, 밤은 별·달·푸른 하늘, 비는 구름을 합성합니다. 산·호수 원경의 색도 시간대에 맞춥니다. 위경도 이미지를 길게 늘이거나 낮 사진 전체를 단순히 어둡게 하는 방식은 사용하지 않습니다.
- [tour_weather.gd](../scripts/environment/tour_weather.gd)의 한 입자 시스템을 투어와 트랙1에서 공유합니다. 트랙1 비의 입자는 화질에 따라240·160·90개이며 지하차도·메뉴·일시정지·동작 줄이기 상태에서는 새 비를 방출하지 않습니다.
- 트랙1의 활성 노면은 이미 분리된 재질에만 젖음 값을 적용합니다. 저녁·밤·비에서는 플레이어 전조등을 켜며 상대 차량은 기존 발광 방식으로 유지합니다. 미리 읽기 단계에서 비의 메시·재질을 준비합니다.

새 설정 문구는 번역 가능한 실제 텍스트이며 원문은 [환경 설정 번역 템플릿](../localization/track_environment.pot)에 있습니다. 공용 설정은 향후 다른 트랙에도 사용할 수 있지만 해당 트랙의 하늘·광원·피난 공간·발광을 먼저 연결한 뒤 적용 대상을 확장해야 합니다.

## 성능과 기록

하늘 합성은 `TIME`을 쓰지 않는 정적인 셰이더이며 방사휘도를 매 프레임 다시 만들지 않습니다. 광원 프리셋은 적용 시 계산하고 터널 보정만 매 프레임 실행합니다. 시간대마다 대형 원경 텍스처를 별도로 상주시키거나 추가 그림자 광원을 만들지 않습니다.

비는 현재 시각 효과이며 차량 마찰·제동·물리는 변경하지 않습니다. 기존 기록과 곡률 캐시를 유지합니다. 도로·지형·충돌 메시를 바꾸지 않으므로 정적 충돌 자료를 다시 만들 필요가 없습니다. 물리까지 바꿀 때는 날씨별 기록 구분과 주행 검증을 별도로 설계해야 합니다.

폴더블 고화질에서 비 입자·젖은 노면·전조등의 실제 GPU 비용은 실기기에서 측정해야 합니다. 현재 구현은 기존 화질 상한과 제한된 비 입자 예산을 사용하며60FPS 보장을 뜻하지 않습니다.

## 검증

[track_environment_checks.gd](../tests/track_environment_checks.gd)는 저장·손상값·재로드, 트랙1의6조합, 밤 강수 광량·전조등·입자 예산·지하차도, 다른 트랙·투어와 재질·설정 격리를 검사합니다. 전체 검사와 실제 화면 확인 절차는 [개발 안내](DEVELOPMENT.md#기본-검사)를 따릅니다.
