# 시작 전 모바일 UI

메인·트랙 선택·차량 선택·튜닝·설정·투어 패스포트와 로딩은 밝은 해안 색상·동일 설계 좌표를 사용합니다. 글자는 이미지에 넣지 않고 번역 가능한 텍스트로 표시합니다.

## 배치와 입력

- [메뉴 배치](../scripts/ui/menu_layout.gd)는1280×720 설계 공간·좌상단 뒤로가기·Android 디스플레이 안전 영역을 관리합니다. HUD·튜닝·로딩은 같은 배율과 원점을 사용하고 터치 역변환도 HUD의 같은 함수로 처리합니다.
- 주요 버튼은 높이80 설계 픽셀입니다. 세로414픽셀 가로 화면에서 약46픽셀입니다. 일반 화면의 좌우30픽셀·하단12픽셀 이상을 확보하고 폴드의 여백은 비율을 보존합니다.
- 튜닝은 왼쪽 옵션만 스크롤하고 차량·카메라·적용 버튼은 고정합니다. 사용자 색상과 변경 폐기는 같은 설계 공간의 시트로 표시합니다. 모달이 열린 동안 배경 포커스를 막고 닫으면 원래 포커스를 복구합니다.
- 긴 번역은 최소22~24 설계 픽셀 뒤 말줄임합니다. 보상 해금 조건은 숫자와 조건을 읽도록 두 줄을 사용합니다. 동작을 가르는 핵심 문구를 이미지에 굽지 않습니다.
- 설정은 음향·동작 감소·그래픽·FPS·자동 가속과 완료입니다. 전체 화면·설치는 웹에서만 표시하고 입력·게임패드 포커스도 같은 조건을 따릅니다. 날씨·시간은 트랙 선택에 둡니다.

## 검사

[모바일 메뉴 검사](../tests/pre_race_ui_checks.gd)와 [밝은 메뉴 검사](../tests/bright_menu_checks.gd)는 작은 가로·폴드 비율, 터치 목표, 뒤로가기, 모달·저장 경계를 검사합니다. [튜닝 검사](../tests/tuning_ui_checks.gd)는 실제 미리보기·적용·취소·긴 번역을 검사합니다. 렌더·입력 변경은 실제 화면으로 설정, 모든 튜닝 탭, 사용자 색상, 변경 취소, 긴 번역, 짧고 긴 로딩을 확인합니다. 캡처 하네스와 감독자 회차 기록은 `build/reports/`에 두며 검토 횟수는 요청받은 상한을 따릅니다.
