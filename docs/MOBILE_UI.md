# 모바일 UI

실행 UI는 승인된 [rev3 이미지 가이드](../art_sources/ui/README.md)를 기준으로 조립합니다. 원화 PNG는 비교 자료이고, 게임에는 [설치된 부품·좌표](../assets/ui/rev3/catalog.json)와 깨끗한 배경만 포함합니다. 제목·버튼·기록은 이미지에 굽지 않고 실제 번역 가능한 글자로 표시합니다.

## 원화와 실제 데이터

[설치 도구](../tools/install_rev3_ui.py)는 [분리 원본](../art_sources/ui/kit/rev3/README.md)에서 실행용 파일을 생성합니다. 원화와 비교 전용 배경, 주행 스냅샷은 설치하지 않습니다. 설치 도구의 `PARTS`에는 실제 사용하는 그림만 등록하고 네이티브 패널의 좌표는 `render: native`로 보존합니다. 새 그림을 연결할 때 같은 목록도 갱신합니다. 아이콘 제거 자국이 남은 빈 패널은 같은 팔레트·모서리의 연속 면으로 조립하며, 아이콘은 원화에서 분리합니다. Noto Sans KR 가변 글꼴은 굵기 650으로 설정하고 [OFL](../assets/ui/rev3/fonts/OFL.txt)을 함께 보존합니다.

[rev3_art.gd](../scripts/ui/rev3_art.gd)는 좌표 변환·부품·현재 화면의 텍스처 수명을, [rev3_interface.gd](../scripts/ui/rev3_interface.gd)는 실제 메뉴·경기 상태와 동작 연결을 맡습니다. 코스 카드의 지도는 실제 Curve3D, 차량 선택·튜닝은 실제 GLB 미리보기, 주행·결과는 실제 월드 위에 표시합니다. 원화의 예시 성능·기록·지도·차량을 경기 데이터로 사용하지 않습니다.

트랙은 세 장씩 넘겨 선택한 뒤 계속 버튼으로 로드합니다. 미리 고른 코스 ID와 현재 월드 ID를 분리하므로 카드 탐색만으로 현재 코스가 바뀌지 않습니다. 튜닝의 저장 탭 번호와 원화 탭 순서는 ID로 연결합니다. 트랙 결과는 트랙 선택, 투어 결과는 모드 선택으로 돌아갑니다.

## 화면비·안전 영역·입력

- 메뉴·주행 모두 Window `EXPAND`로 기기 화면을 채웁니다. [menu_layout.gd](../scripts/ui/menu_layout.gd)가 Android 안전 영역 안에 1280×720 설계 공간의 균일 배율·원점을 구합니다. 그림과 터치는 같은 변환과 역변환을 사용합니다.
- 4:3~2:1에서 본문·사진·미리보기 비율을 유지합니다. 배경은 전체 화면을 채워 자르고, 헤더·하단 버튼·상단 HUD·주행 조작은 안전 영역 가장자리에 고정합니다. 버튼을 넓힐 때 아이콘은 늘리지 않습니다.
- 작은 메뉴 스위치·화살표는 실제 입력 영역을 최소 80 설계 픽셀로 넓힙니다. 주요 네이티브 튜닝 버튼도 충분한 높이를 유지합니다. 겹칠 수 있는 주행 원형 버튼은 포인터와 가장 가까운 활성 버튼 하나가 소유합니다.
- 튜닝 옵션만 스크롤하고 차량·카메라·적용은 고정합니다. 색상·변경 폐기는 안전 영역 안의 시트이며, 열려 있는 동안 배경의 터치·키보드·게임패드 포커스를 막습니다.
- 사용자 색상은 색상환·이전/새 색상·RGB 슬라이더를 공유합니다. 확인은 편집값을 유지하고 취소·뒤로가기는 팝업 진입 전 색상으로 복구합니다. 실제 영구 저장은 적용 버튼에서만 수행하며 실패하면 편집값을 보존합니다.
- 긴 번역은 글자 크기 조절·말줄임·두 줄 배치를 사용합니다. [menu_text.gd](../scripts/ui/menu_text.gd)의 64개 Label 풀은 입력을 가로채지 않고 화면 전환 때 지난 문자를 숨깁니다.

[race_hud_layout.gd](../scripts/ui/race_hud_layout.gd)는 투어·트랙의 동일한 상단 여백·미니맵을 관리합니다. 조이스틱과 브레이크는 하단 중심 높이·바깥 여백을 맞추며 반전·크기 프리셋도 보존합니다. 하이브리드의 셀 수·재충전, 충전형/연속형 니트로, 실제 출발 초와 회복 상태를 표시합니다.

설정은 음악·효과음을 각각 기본 70·50, 최대 100으로 독립 저장합니다. 날씨·시간은 트랙 선택에 두고 전체 화면·설치는 웹에서만 표시합니다. 키보드·게임패드도 같은 동작과 현재 좌표를 사용합니다.

## 수명과 검증

화면을 바꾸면 이전 텍스처 참조를 직전 그리기 이후 해제합니다. 배경을 모두 preload하지 않으며, 주행 중 메뉴 배경을 보유하지 않습니다. 튜닝의 독립 뷰포트는 변경·회전·시연 때만 갱신하고 샵 종료 시 해제합니다. [modal_motion.gd](../scripts/ui/modal_motion.gd)는 닫기 콜백을 한 번만 실행하고 화면 교체 시 취소합니다. 조작 설정의 뒤로가기는 부모 설정으로 한 단계 돌아갑니다.

[원화·입력 검사](../tests/pre_race_art_checks.gd)는 4:3·16:9·2:1과 작은 휴대폰의 실제 메뉴 동작·터치 영역·배경 해제를, [모바일 메뉴 검사](../tests/pre_race_ui_checks.gd)와 [튜닝 검사](../tests/tuning_ui_checks.gd)는 시트·저장·취소·미리보기 수명을 검사합니다. HTML의 픽셀 재조립 검증과 실제 Godot 렌더·입력 검증은 별개입니다. 캡처·검토 회차·측정값은 Git에서 제외한 `build/reports/`에 두고 요청받은 검토 상한을 따릅니다.
