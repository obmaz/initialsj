# 도로 안내와 속도 스냅샷

[roadside_guidance.gd](../scripts/environment/roadside_guidance.gd)는 주행·충돌 형상과 분리된 GLB 배치를 소유합니다. 투어2번째 줄의 정글·도시,4번째 줄의 유적·서울·후지·네온, 트랙2에 속도 카메라를 설치합니다. 직선성이 높은 구간을 고르며 터널·다리·점프·고가도로를 피합니다. 다른 지역에는 속도 측정 구조물을 임의로 늘리지 않습니다.

## 측정과 전광판

[speed_trap.gd](../scripts/environment/speed_trap.gd)는 실제 플레이어의 주행 거리·속도·접지를 사용합니다. 측정선 앞뒤의 연속된 순방향 주행에서 속도를 보간하고 km/h로 기록합니다. AI의 속도·최고속도 제원·임의 숫자를 표시하지 않습니다. 공중·충돌 날림·리스폰 보호·도로 밖·큰 거리 이동·역주행은 측정하지 않습니다. 같은 주회에서는 한 번만 촬영하며 다음 주회에 갱신합니다.

카메라는 갓길 바깥의6.3m 지주에 있고180m 뒤에 대형 전광판을 놓습니다. 촬영 후0.85초가 지나면 전광판에 측정 당시 속도를 표시합니다. 이후 차량이 감속해도 표시값은 바뀌지 않습니다. 측정 전에는 `---`, 경기 재시작 시에는 측정값·지연·플래시를 초기화합니다. 기록 파일을 매번 쓰지 않습니다.

전광판은 지주·트러스·점검 발판을 가진 실척 GLB이며 실제 도로와 가드레일 폭에 맞춰 지주 간격을 늘립니다. 표시부는 단순 LED 셰이더와 변경 시에만 갱신하는 Label3D를 사용합니다. 별도 렌더 뷰포트나 프레임마다 새 텍스처를 만드는 방식은 사용하지 않습니다. 카메라 플래시는 짧은 발광 표시면이며 실시간 광원을 추가하지 않습니다.

## 커브 안내

주간의 기존 반사 인쇄 안내판과 두꺼운 케이스는 유지합니다. 야간 항만·네온 투어는 표시면만 [digital_chevrons.gdshader](../shaders/digital_chevrons.gdshader)의 LED 점행렬로 바꾸며, 기존 좌우 반사 변환과 동일한 방향으로 화살표가 흐릅니다. 개체마다 CPU에서 위치·MultiMesh 버퍼를 다시 쓰지 않습니다. 동작 감소 옵션에서는 흐름을 멈춥니다. 공유 원본 MultiMesh는 직접 바꾸지 않고 해당 구간의 복제본을 사용합니다.

모든 트랙·투어의 실제 곡선에서 같은 방향으로 꺾이는 구간과 최대 곡률을 찾아 급커브를 분류합니다. 진입 전에60·105·150m 간격으로45·60·75도 노면 화살표를 배치하고 좌우 반사로 방향을 맞춥니다. 표식은 미터 단위 GLB이며 도로의 경사·뱅킹을 따릅니다. 좁은 도로에서는 비율을 유지하며 축소해 가장자리 밖으로 나가지 않습니다. 구간당 각도별 MultiMesh 하나로 묶습니다.

## 모델·구간 수명

모델은 `models/props/speed_camera`, `speed_display`, `digital_chevrons`, `bend_arrow_45`, `bend_arrow_60`, `bend_arrow_75`, `lake_cruiser` 팩에서 형상·씬·재질·출처를 함께 관리합니다. 원본 GLB는 같은 ID의 `model_sources/props/`에 보존합니다. 범선은 수선 피벗0m, 약56m 길이·35m 주 돛대를 가진3마스트 모델이며 후지 트랙 호수의 도로에서75m 이상 떨어진 위치에 둡니다.

[오프라인 제작 도구](../tools/bake_roadside_models.py)는 기존 원본을 기본적으로 건너뛰며 명시적인 `--replace`에서도 이전 바이트를 해시별로 백업한 뒤 재생성합니다. 정점색 형상·버퍼 도구는 [glb_shapes.py](../tools/glb_shapes.py), 바이트 읽기·쓰기는 [glb_geometry.py](../tools/glb_geometry.py)를 공유합니다. GLB 임포트 후에는 팩 전용 재질의 정점색 사용 설정도 유지합니다.

투어 미리보기는 소품 씬까지 비동기 사전 읽기 목록에 넣습니다. 형상 연결·안내 계획·LED·노면 표식·계측기 조립을 별도 큐 단계로 나누고 재질 준비 후 구간을 공개합니다. 해당 구간을 지나면 안내판·측정값·소품 노드도 구간과 함께 해제됩니다. 도로·장벽 충돌 캐시를 시각 장식 때문에 바꾸지 않습니다.

## 낙석과 HUD

트랙5의 낙석은 현재 속도에 따라160~310m 앞에서 시작하며 약0.95초 예고 뒤1.9초에 걸쳐 떨어집니다. 기존보다 접근한 시점에 공중 바위가 보이도록 합니다. 도로에 남는9개는 기존 치수·충돌체·통과 폭을 유지합니다. 착지 후 사라지는 추가15개의 공중 조각은2.1배, 도로 밖의24개는1.6배로 표시합니다. 도로 밖 낙하는 여전히 물리 노드 없는 MultiMesh이며 착지한 뒤에는 매 프레임 변환을 갱신하지 않습니다.

니트로 사용 중 화면 중앙의 `NITRO`·`OVERDRIVE` 안내는 표시하지 않습니다. 연료 게이지·조작 버튼과 후류·기술 보상 안내는 유지합니다.

[roadside_guidance_checks.gd](../tests/roadside_guidance_checks.gd)는 실제 주행 연결·측정 속도·지연 표시·주회·잘못된 통과 제외·화살표 여유 폭·야간 동작 감소·범선 위치를 검사합니다. [낙석 검사](../tests/rockfall_checks.gd)는 늦어진 낙하·공중 조각 크기와 기존 도로 장애물9개·차체 통과 폭을 함께 검사합니다. 실제 렌더러에서도 숫자 가독성·LED 흐름·노면 안내·범선 색상과 실척을 확인합니다.
